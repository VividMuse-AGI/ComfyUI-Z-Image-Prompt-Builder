# Z-Image 中文提示词生成器

通过写真预设、结构化模块和确定性随机种子，离线生成中英文自然语言正向提示词。节点不调用外部翻译服务或在线 API。

## 基本流程

1. 选择**预设**、**提示词密度**和**随机范围**。
2. 通过**当前编辑模块**切换画面基础、人物、发型、服装、姿态动作、场景、摄影、视觉表现。
3. 每个字段可选择**跟随预设**、**随机抽取**、**不使用**或具体选项。
4. 可在**自由提示词**中补充自定义描述，并选择**拼接位置**。
5. 将**中文提示词**或**英文提示词**连接到对应的文本编码节点。

**🎲 设置随机组合**会按当前随机范围准备随机字段（若处于“仅启用当前模块”隔离状态则只准备当前模块），不会立即执行节点。点击 ComfyUI **Run** 后，在**查看结果**中查看实际输出与估算 Token 数。只修改种子不会把固定字段变成随机，也不保证每次生成不同文本。**仅启用当前模块**会在确认后清空其他模块选项与已应用用户文本，保留自由提示词与已导入词库；仅切换**当前编辑模块**不会清空任何内容。

**清空内容…** 提供**清空结构化内容**与**清空全部提示词**，操作前可核对清除范围。已导入词库、已保存卡片/预设以及分辨率设置均会保留。**清空自由提示词**就近保留在输入框旁；移除词库会保留已写入正文的文本。

## 界面语言

在 ComfyUI 设置中搜索 **Z-Image Prompt Builder: Interface language / 界面语言**，可切换 Auto / 中文 / English。界面语言只影响显示标签，不改变保存的中文字段名与选项值，保证旧工作流完全兼容。

英文输出会将内置字段渲染为英文，自由提示词和用户 TXT 片段按原文保留。如需纯英文结果，请填写英文自由提示词或 TXT 片段。

右键菜单**我的预设与卡片**可保存、组合应用或导入预设与卡片；常用管理项在**管理…**中。通过**随机设置与检查**可锁定重要字段并检查组合冲突。**精简**与**标准**档在特写/近景构图下会自动隐藏画外的内置鞋袜与腿脚动作，**详细**档保留全部细节。

## 分辨率设置

在“画面基础”模块中设置**画面比例**、**百万像素（MP）**和**尺寸整除倍数**。新节点默认 **1.00 MP**（100 万像素），整除倍数默认 **16**（直接适配 Z-Image 16 像素对齐，支持 8–128 内 4 的倍数）。计算时严格保持画面比例，预览行会实时显示实际宽高与像素数（例如 4:5 在 2 MP、16 倍数下为 `1280 × 1600`，约 `2.048 MP`）。

点击预览行可展开切换**保持比例计算（推荐）**或**按像素计算**（后者每单位为 1024×1024 像素，宽高分别取整）。旧工作流仍保留原有的固定推荐尺寸，直到你修改百万像素、整除倍数或主动切换计算方式。

请将**推荐宽度 / 推荐高度**连接到实际的 latent 节点输入。随机比例或外部连线时预览显示待定；自由提示词和 TXT 中的比例文字不会自动解析。
