# Z-Image 画面基础

生成模块化提示词链中的基础画幅与主题部分，包括画面比例、成像媒介、写真大类与写真主题，并输出推荐画布尺寸。

将**组合提示词**连接到下一个模块节点的**前置提示词**；如需同步串联英文链，将**英文提示词**连接到**前置英文提示词**。可使用 `Ctrl+B` 旁路当前模块。

## 分辨率设置

设置**画面比例**、**百万像素（MP）**和**尺寸整除倍数**。新节点默认 **1.00 MP**、整除倍数 **16**（原生适配 Z-Image 16 像素对齐，支持 8–128 内 4 的倍数），计算时严格保持画面比例。例如 4:5 在 2 MP、16 倍数下输出 `1280 × 1600`（`2.048 MP`）。

点击预览行可切换**保持比例计算（推荐）**或**按像素计算**（每单位 1024×1024 像素，宽高分别取整）。旧工作流保留已保存的固定尺寸，直到手动调整百万像素、整除倍数或切换模式。

请将**推荐宽度 / 推荐高度**连接到 latent 节点；随机或外部连线比例会显示待定提示。清空本模块不会重置尺寸计算参数。
