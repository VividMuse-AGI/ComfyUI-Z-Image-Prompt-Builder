# Z-Image Clothing

Builds outfit structure, garment type, color, material, pattern, fit, legwear, footwear, and accessory descriptions.

**Outfit Structure** controls which garment branch is shown: dress, jumpsuit, separates, suit, or layered styling. Hidden branch values remain saved but are excluded when they are not part of the active outfit structure.

Chain the Chinese and English inputs/outputs separately. Use `Ctrl+B` to bypass the module.
