# TXT Module Library — English Format Guide
# Lines before the first "##" heading are comments and are ignored during import.
# This library stores one prompt module per entry; it is not a complete prompt library.
#
# Required block format:
# 1. Title: ## My module title
# 2. Module: Module: Canvas | Person | Hair | Clothing | Pose & Action |
#    Scene | Photography | Visual Style | Custom
# 3. Tags: optional. Use "Tags: tag one, tag two" or "Tag: tag one".
# 4. Body: describe only the selected module. Keep it concise, positive, and
#    ready to join directly to adjacent prompt fragments.
# 5. Custom does not replace any of the eight standard modules. Use it for a
#    product prop, poster whitespace, narrative requirement, or other add-on.
# 6. Separate entries with --- on its own line.
# Chinese keywords (模块：/标签：) and Chinese module names remain supported.
# Limits: 1 MB per file, 500 entries total, 20,000 characters per entry.
