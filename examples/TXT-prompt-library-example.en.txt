# TXT Prompt Library — English Format Guide
# Lines before the first "##" heading are comments and are ignored during import.
#
# Recommended block format:
# 1. Title: start a line with two hash signs and one space: ## My prompt title
# 2. Tags: optional. Use "Tags: tag one, tag two" or "Tag: tag one".
#    Tags are stored for organization only; they are never added to the prompt.
# 3. Prompt body: every line after Title/Tags and before the next separator is
#    stored as the prompt. It may be one line or multiple lines.
# 4. Separator: put --- on its own line between entries.
# 5. Plain-line mode: if the file contains no ## headings, every non-empty,
#    non-comment line becomes one complete prompt.
# 6. Write direct, positive natural language. Organize details as subject,
#    action, environment, lighting, camera, composition, and visual finish.
# 7. Omit unwanted details instead of writing negative instructions.
# Limits: 1 MB per file, 500 entries total, 20,000 characters per entry.
