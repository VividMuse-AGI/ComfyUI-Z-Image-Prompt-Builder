# TXT结构化模块词库写法说明（本说明位于第一个条目前，导入时会自动忽略）
# 这种词库既可替换八个标准模块，也可启用一个独立的自定义模块；它不是完整提示词词库。
# 1. 条目标题：另起一行输入两个半角井号、一个空格，再写便于识别的标题。
# 2. 标准模块：每条都必须填写“模块：名称”，八个标准名称为：
#    画面基础、人物、发型、服装、姿态动作、场景、摄影、视觉表现。
# 3. 自定义模块：填写“模块：自定义”。启用后不会替换标准模块，而是作为独立片段追加在八个标准模块之后。
# 4. 可识别别名：基础画面；人物设定、角色；头发；穿搭；姿态、动作；环境；镜头；视觉、光影色彩。
# 5. 标签：格式为“标签：词语1，词语2”，可以省略；标签不会拼接到最终提示词。
# 6. 正文：标准条目只描述对应模块；自定义条目适合写商品道具、版式留白、叙事补充等额外要求。
# 7. 应用方式：选择“词库模块”和条目后点击应用；自定义类型的按钮会显示“启用自定义模块”。
# 8. 分隔：不同条目之间建议使用三个半角短横线“---”单独成行。
# 9. 内容建议：使用简洁、肯定、可直接拼接的中文自然语言；没有的内容直接省略，不写“不佩戴”等反面表达。
# 文件限制：最大1MB、全部模块合计最多500条、单条正文最多20000个字符。
