# v0.8.0

## 中文

新增双语“素材搜索与收藏”，覆盖完整节点、八个独立模块及两个 TXT 节点。节点数量仍为 11 个。

### 新功能

- 按中英文名称和实际短语搜索；多个关键词全部匹配，特殊字符按文字处理。完整节点搜索当前编辑模块，独立模块搜索其可用字段。
- 导入 TXT 后可搜索其条目，并使用标签、无标签和模块条件筛选。多个标签满足任一即可，再与关键词和模块条件共同筛选。
- 选择条目只预览；点击“应用所选条目”才更新原控件。关闭、取消及没有结果都不改已有内容；独立 TXT 节点需在手动模式应用。
- 收藏和最近 20 条成功应用记录保存在当前浏览器、当前站点；支持收藏 JSON 导出／导入，文件只有条目标识，不含 TXT 正文。恢复 TXT 收藏需重新导入相同文件名和内容的词库。
- 存储不可用时提示并降级为本页内存；补充异步关闭、删除节点关闭、事件隔离和中文输入法保护。

### 兼容与验证

筛选只影响列表，不改变随机候选、种子、后端参数、提示词或尺寸。字段、端口、TXT 格式和分段规则保持兼容，没有新增在线调用或 Python 依赖；用户 TXT 内容不自动翻译。

发布范围的干净副本在 Windows Python 3.10.11 通过 187 项 Python 测试，在 Node.js 22.20.0 通过 22 组前端回归；生成目录一致性和安装包必需文件检查通过。实机代表矩阵覆盖 ComfyUI 0.39.1／前端 1.53.10 的中文／英文及经典／Nodes 2.0，包含上传、搜索应用、保存恢复、收藏实际下载与导入；实体中文输入法由用户补验确认。未生图，未量化浏览器绘制时延，也不宣称覆盖全部宿主版本。

准确范围见[验收记录](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.8.0/docs/testing/2026-10-07-library-discovery-acceptance.md)。正式附件由发布流程在 Ubuntu Python 3.10／Node 22 CI 通过后生成。

### 安装

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.8.0.zip**，用同页 **SHA256SUMS.txt** 校验后解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，无需改名。Git 安装可在节点目录执行 `git pull --ff-only`；更新后重启 ComfyUI 并刷新浏览器。

## English

This release adds bilingual **Search & Favorites** to the full builder, eight standalone modules, and both TXT nodes. The package still contains 11 nodes.

### Features

- Search Chinese and English names and actual phrases. All space-separated keywords must match; special characters are literal. The builder searches its current module, while standalone modules search their available fields.
- After importing TXT, search entries and filter by tags, untagged entries, and module. Selected tags use OR, combined with the query and module restriction using AND.
- Selecting an entry previews it. Only **Apply Selected Entry** updates the original widget. Closing, cancelling, or finding no results leaves inputs unchanged. Standalone TXT nodes require Manual Selection to apply an entry.
- Favorites and the last 20 distinct successfully applied entries are stored per browser and site. Export/import JSON contains entry references only, not TXT bodies. Restore TXT favorites by reimporting the same filename and library content.
- Unavailable storage falls back to page memory with a warning. Added async-close and node-removal guards, event isolation, and Chinese input-method protection.

### Compatibility and verification

Filters affect the list only, not random candidates, seeds, backend parameters, prompts, or dimensions. Fields, ports, TXT formats, and paragraph rules remain compatible. No online calls or Python dependencies were added; user TXT content is not automatically translated.

A clean copy of the release scope passed 187 Python tests on Windows Python 3.10.11 and 22 frontend suites on Node.js 22.20.0, plus generated-catalog consistency and required-package-file checks. Representative live cases covered Chinese/English and Classic/Nodes 2.0 on ComfyUI 0.39.1 / frontend 1.53.10, including uploads, search/apply, workflow restoration, and actual favorite-file download/import. The user confirmed physical Chinese IME behavior. No images were generated; browser paint latency and every host version were not verified.

See the [acceptance record](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.8.0/docs/testing/2026-10-07-library-discovery-acceptance.md) for exact scope. Official assets are built only after Ubuntu Python 3.10 / Node 22 release CI passes.

### Installation

Download **ComfyUI-Z-Image-Prompt-Builder-v0.8.0.zip**, verify it with **SHA256SUMS.txt**, and extract it into `ComfyUI/custom_nodes`. The archive root is already named `ComfyUI-Z-Image-Prompt-Builder`. Git installations can run `git pull --ff-only` in the node directory. Restart ComfyUI and refresh the browser after updating.
