# v0.6.0

## 中文

本次更新新增独立 TXT 词库随机抽取，扩充 69 条受约束短语，并修复组合兼容与 Nodes 2.0 界面问题。节点数量仍为 11 个。

### 新功能与修复

- 两个独立 TXT 词库节点提供“手动选择／随机抽取”和随机种子；同一词库、顺序、模块及种子可复现结果，不同种子允许抽到相同条目。
- TXT 模块词库只在当前模块内抽取，支持自定义模块；空库或空范围只保留前置文本，不跨模块补选。
- 手动草稿独立保留；只读“上次随机结果”显示实际执行种子、标题与正文，不误显示下一次种子。支持工作流保存恢复、缓存回显及 API 调用。
- 新增 69 条短语：姿态动作 40、服装 14、头饰 6、场景 9。手动选项与随机池共用，具备中文／英文输出和英文界面映射。
- 增加主题、场景、鞋履、景别和穿搭兼容筛选；修复部分单字段漏写、发型回退冲突及英文措辞。
- 修复 Nodes 2.0 动态按钮漏翻译、随机模块切换后禁用外观不一致的问题，保持控件内部名称及旧工作流字段兼容。

### 兼容与范围

- 旧工作流默认手动模式，原 STRING 端口、前置文本与分段行为保留。完整生成器内部的 TXT 面板不新增自动随机功能。
- 词库和规则扩充后，相同种子的随机组合可能与旧版不同；同一版本内可复现。固定预设除已说明的措辞修正外保持原输出。
- 编辑器种子上限为 `9007199254740991`，API 支持精确 uint64；API 客户端需自行更新后续种子。
- 用户 TXT 不自动翻译。词库会保存在工作流并发送给所连接的 ComfyUI 后端，不上传第三方服务；分享工作流前检查是否包含私人词库。
- 不包含参考照片、六条外部数据候选、本机记录或浏览器工具；不增加第三方运行依赖。

### 验证与安装

干净副本通过 159 项 Python、19 组前端及 9 次隔离 CPU 文本执行；中英文、经典与 Nodes 2.0 的真实界面验收、旧工作流、长文本安全显示和 API 重放已通过。验证不运行生图，也不保证所有宿主版本或模型输出效果。

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.6.0.zip**，解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，无需改名。先备份工作流和自定义词库，避免保留多个启用副本。Git 安装用户在节点目录运行 `git pull --ff-only`。重启 ComfyUI 后按 **Ctrl+F5** 刷新；使用 **SHA256SUMS.txt** 核对安装包。

## English

This release adds seeded sampling to the standalone TXT libraries, 69 constrained phrases, compatibility corrections and Nodes 2.0 UI fixes. The package still registers 11 nodes.

### Features and fixes

- Both standalone TXT nodes offer Manual / Random Selection with a seed. The same library, ordering, module and seed reproduce a result; different seeds may select the same entry.
- Module sampling stays within the selected module, including Custom. Empty libraries or scopes pass through upstream text only.
- Manual drafts are preserved separately. Last Random Result shows the executed seed, title and body rather than the next seed. Workflow restoration, cached results and headless API calls are supported.
- Added 69 bilingual phrases: 40 pose/action, 14 clothing, 6 headwear/accessories and 9 scene entries, shared by manual options and constrained random pools.
- Improved theme, scene, footwear, framing and clothing compatibility; corrected missing single-field output, conflicting hairstyle fallbacks and English wording.
- Fixed untranslated dynamic buttons and inconsistent disabled states in Nodes 2.0 while preserving stable widget identities and saved fields.

### Compatibility and scope

- Existing workflows default to manual selection. Existing STRING ports, upstream text and paragraph behavior are preserved. The full builder's embedded TXT panels do not gain random sampling.
- Expanded libraries and rules may change an old seed's random result; results remain reproducible within the same version. Fixed presets retain their output except for documented wording corrections.
- Editor seeds are limited to `9007199254740991`; the API supports exact uint64 values. API clients must update subsequent seeds themselves.
- User TXT content is not translated automatically. Libraries are saved in workflows and sent to the connected ComfyUI backend, not third-party services. Review private content before sharing a workflow.
- Reference photos, the six external-dataset candidates, machine-specific records and browser tooling are excluded. No third-party runtime dependencies were added.

### Verification and installation

The clean snapshot passed 159 Python tests, 19 frontend suites and 9 isolated CPU text executions. Real Chinese/English UI checks in classic and Nodes 2.0 layouts, old workflows, safe long-text rendering and API replay passed. These checks did not generate images and do not guarantee every host version or model result.

Download **ComfyUI-Z-Image-Prompt-Builder-v0.6.0.zip** and extract into `ComfyUI/custom_nodes`. Its root is already named `ComfyUI-Z-Image-Prompt-Builder`. Back up workflows and custom libraries first; avoid multiple enabled copies. Git users can run `git pull --ff-only` in the node directory. Restart ComfyUI and refresh with **Ctrl+F5**. Verify the archive against **SHA256SUMS.txt**.
