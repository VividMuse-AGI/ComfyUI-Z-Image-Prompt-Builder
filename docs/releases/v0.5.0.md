# v0.5.0

## 中文

- 新增百万像素（MP）与尺寸整除倍数设置，按所选画面比例换算宽高，修复分辨率控件遮挡。
- 完整节点、八个独立模块与两个 TXT 节点支持分段输出；旧工作流保留连续格式。
- 新增右键用户预设管理、JSON 导入导出、随机字段锁定与组合检查。
- 优化主题、服装、动作和摄影之间的随机兼容关系；补充动作链、配饰套组和场景选项，保留十套固定预设原文。
- 修复部分英文输出遗漏、TXT 重名和预设导入校验问题，以及经典模式和 Nodes 2.0 的中英文界面刷新问题。
- 提供四套无需生图模型的文本预览工作流。

### 安装与升级

下载附件 **ComfyUI-Z-Image-Prompt-Builder-v0.5.0.zip**，解压到 `ComfyUI/custom_nodes`。压缩包内部固定为 `ComfyUI-Z-Image-Prompt-Builder`，无需改名；不要同时保留多个启用的节点副本。升级前建议备份工作流和自定义词库，升级后重启 ComfyUI 并刷新浏览器。

Git 安装用户可在节点目录运行 `git pull --ff-only`。`SHA256SUMS.txt` 提供安装包校验值。GitHub 自动生成的 Source code 源码包仍带版本后缀，手动安装推荐使用上面的附件。

### 兼容说明

- 原输出端口顺序保留；旧尺寸设置及旧工作流兼容处理保留。
- 新版随机规则可能改变旧种子的组合结果，同版本内仍可复现。
- 自由提示词和 TXT 正文原样保留，不会自动翻译。
- 自动测试覆盖代码行为，不能代替全部动作及随机组合的多种子生图验收。

完整变更见 [CHANGELOG](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.5.0/CHANGELOG.md)。

## English

- Set a megapixel budget and dimension divisibility while preserving the selected aspect ratio. Resolution controls no longer overlap.
- Paragraph output is available in the full builder, all eight module nodes, and both TXT nodes. Legacy workflows retain continuous output.
- Manage user presets, import/export JSON, lock random fields, and inspect combinations from the context menu.
- Improved random compatibility across themes, clothing, poses, and photography; expanded action chains, accessory sets, and scenes without rewriting the ten fixed presets.
- Fixed missing English fragments, duplicate TXT titles, preset validation, and bilingual UI refresh in classic mode and Nodes 2.0.
- Four text-preview example workflows require no image-generation model.

### Install or update

Download **ComfyUI-Z-Image-Prompt-Builder-v0.5.0.zip** and extract it into `ComfyUI/custom_nodes`. Its root folder is already named `ComfyUI-Z-Image-Prompt-Builder`; do not keep multiple enabled copies. Back up your workflows and custom libraries before upgrading, then restart ComfyUI and refresh the browser. Git installations can use `git pull --ff-only` from the node directory.

Verify the archive against **SHA256SUMS.txt**. Prefer the attached installation ZIP over GitHub's automatically generated Source code archives, which include the version in their root folder name.

Existing output-port order and legacy resolution settings are preserved. Updated random rules may change results for old seeds, while remaining reproducible within this version. Free text and TXT content are preserved verbatim, not automatically translated. Automated tests validate code behavior, not image quality across every random combination.

See the [full changelog](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.5.0/CHANGELOG.md) for details.
