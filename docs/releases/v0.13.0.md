# v0.13.0

## 中文

本版聚焦卡片整理：人物／穿搭卡和拍摄方案卡新增收藏、排序及筛选后批量选择，不增加节点或画布高度。

- **更容易找到卡片**：收藏星标、仅收藏、默认／名称／收藏优先排序，与原搜索共同使用。筛选隐藏当前卡片后清空选择，不自动应用另一张卡；取消收藏不等于删除。
- **导出选择更明确**：卡片包支持搜索、仅看收藏、选择匹配、取消匹配和清空。隐藏勾选仍保留，计数和完整名单显示真正将导出的内容。只导出筛选结果时，先清空，再选择匹配。
- **可撤销的整理操作**：卡片与收藏更新使用同一事务。重命名迁移收藏，删除清理引用，导入覆盖同一身份保留本地收藏；新增导入默认未收藏。
- **格式保持兼容**：单卡／卡片包仍为 v1，导出配置、不携带收藏。收藏属于当前节点并随工作流保存；异常数据只读降级，重置需确认。搜索、排序和收藏不改变提示词、随机池或字段锁。

### 使用与安装

右键节点 → **卡片管理 / 模块锁定**；拍摄方案从该面板进入。收藏后请保存工作流。保留 11 个节点、现有端口、每类最多 100 张卡及 1 MiB 文件上限，无新增依赖或在线服务。

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.13.0.zip**，使用 **SHA256SUMS.txt** 校验，解压至 `ComfyUI/custom_nodes`。安装包内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`。Git 安装可在备份本地修改后更新。重启 ComfyUI 并刷新页面，避免同时启用多个副本。

## English

This release focuses on card organization: favorites, sorting and filtered batch selection for Person / Outfit Cards and Shoot Plan Cards, without extra nodes or node height.

- **Find cards faster:** favorite stars, Favorites Only, Default Order, Name Order and Favorites First work alongside search. Hiding the current card clears its selection instead of applying another card. Unfavoriting does not delete a card.
- **Explicit export selection:** search, show favorites, select/deselect matches or clear the selection. Hidden checked cards remain selected; the count and full export list show what will actually be exported. To export only matches, clear first, then select matches.
- **Undoable organization:** card and favorite changes share one transaction. Renaming moves the favorite reference; deletion removes it. Importing over the same identity retains its local favorite, while new imports are not favorited.
- **Compatible files:** cards and packs remain v1 and exclude favorites. Favorites belong to the node and are saved with its workflow. Invalid data falls back to read-only and requires confirmation to reset. Search, sorting and favorites do not change prompts, random pools or field locks.

### Usage and installation

Use the node context menu → **Cards / Module Locks**, then optionally **Shoot Plan Cards**. Save the workflow after favoriting. The package retains 11 nodes, existing ports, the separate 100-card quotas and the 1 MiB file limit, with no new dependencies or online services.

Download **ComfyUI-Z-Image-Prompt-Builder-v0.13.0.zip**, verify **SHA256SUMS.txt**, and extract into `ComfyUI/custom_nodes`. Its internal root is `ComfyUI-Z-Image-Prompt-Builder`. Git installations may update after backing up local edits. Restart ComfyUI and refresh the page; avoid duplicate active installations.
