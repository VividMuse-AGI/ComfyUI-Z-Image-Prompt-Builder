# v0.15.0

2026-11-04

## 中文

新增 **发型卡与姿态动作卡**，让人物、发型、穿搭和动作分别保存与复用。

- 发型卡保存 9 个字段，姿态动作卡保存 10 个字段，包含完整模块与隐藏分支。完整节点和对应独立节点都支持保存、应用、锁定、收藏和 JSON 交换。
- 从当前设置保存，或从“实际执行结果”保存该次解析值；结果保存不会读取后来改动的编辑器值，不会重新随机、应用卡片或新增锁定。
- 完整节点“卡片快捷组合”增加发型、姿态动作，形成五个选择器；均默认保持当前，按所选模块预览和应用。
- 单卡和快捷组合共用事务保护，支持一次撤销／重做、失败回滚及过期预览阻断。明确提示隐藏字段、全空卡清空行为、已有锁定覆盖，以及动作道具需自行匹配。

入口：右键节点 → **卡片管理 / 模块锁定**。卡片包使用 **导入卡片包**，不能使用“素材搜索与收藏 → 导入收藏”。两个入口的数据格式不同。

### 兼容与安装

- 保持 11 个节点、现有端口、提示词和随机算法，不新增依赖或在线服务。
- 四类内容卡合计每节点最多 100 张；拍摄方案卡限额独立。文件上限仍为 1 MiB。
- 格式结构仍为 v1，但新模块类型需要 v0.15.0 或以上。旧人物／穿搭卡可继续读取；v0.14.0 不支持包含发型／姿态动作的单卡、混合包或含这些卡片的工作流降级编辑。
- 升级前保存工作流备份。需要降级时优先恢复备份，不要认为导出一个旧类型卡片包就能转换整个工作流。
- 下载本页附件 `ComfyUI-Z-Image-Prompt-Builder-v0.15.0.zip`，核对同页 `SHA256SUMS.txt`；包内根目录固定为 `ComfyUI-Z-Image-Prompt-Builder`。避免同时启用多个副本，重启 ComfyUI 并刷新页面。

中文 Classic、英文 Nodes 2.0、真实撤销／重做、保存刷新与 TXT 阻断已验证；用户确认独立节点混合包导入及小窗口操作正常。未运行生图，不承诺人物身份或人体姿态一致。

## English

**Hair Cards and Pose / Action Cards** let you save and reuse person, hair, outfit and pose descriptions independently.

- Hair Cards capture 9 fields and Pose / Action Cards capture 10, including the complete module and hidden branches. The full builder and corresponding standalone nodes support saving, applying, locking, favorites and JSON exchange.
- Save current settings or resolved values from a specific **Actual Execution Result**. Result saving does not read later editor changes, reroll randomness, apply the card or add locks.
- **Quick Card Combination** now offers five selectors, including Hair and Pose / Action. Each defaults to **Keep Current**; preview and apply only selected modules.
- Single-card and combination application share transaction protection, one-step undo/redo, rollback and stale-preview guards. Previews explain hidden fields, clearing by all-Unused cards, overwriting locked fields and the need to match props to poses.

Entry: node context menu → **Cards / Module Locks**. Use **Import Card Pack** for card packs, not **Search & Favorites → Import Favorites**. These are different formats.

### Compatibility and installation

- Still 11 nodes, with existing ports, prompt output and randomization algorithms; no new dependencies or online services.
- All four content-card types share a 100-card limit per node. Shoot Plan Cards have a separate limit. Files remain limited to 1 MiB.
- The structure remains v1, but new module types require v0.15.0 or later. Existing Person / Outfit Cards remain readable. v0.14.0 does not support new-type single cards, mixed packs or downgrade editing of workflows containing them.
- Back up workflows before upgrading. Restore the backup to downgrade; exporting an old-type-only pack does not convert the entire workflow.
- Download the attached `ComfyUI-Z-Image-Prompt-Builder-v0.15.0.zip` and verify `SHA256SUMS.txt`. The internal root is `ComfyUI-Z-Image-Prompt-Builder`. Avoid duplicate active installations, restart ComfyUI and refresh the page.

Chinese Classic, English Nodes 2.0, real undo/redo, save/refresh and TXT guards were verified. The user confirmed mixed-pack imports into standalone nodes and smaller-window interaction. No images were generated; fixed prompts do not guarantee identity or exact anatomy.
