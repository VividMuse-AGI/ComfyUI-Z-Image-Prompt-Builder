# v0.16.0

2026-11-05

## 中文

本版聚焦卡片使用体验：**知道文件该从哪里导入，也能在应用之前看懂卡片保存了什么。**

- 导入素材收藏、内容单卡、内容卡包、拍摄方案和用户预设时，识别文件声明的格式；入口选错时给出正确路径，不再只有笼统的格式错误。目标入口仍会校验完整数据，不会自动转换或应用。
- 内容卡管理、拍摄方案卡及快捷组合显示只读“卡片内容”摘要。内容卡显示主要字段及明确清空值提示，拍摄方案标明包含模块与本次应用范围。摘要不是全部字段，也不替代下方应用差异和完整字段查看。
- 刷新列表、保持当前或无匹配选择时，旧摘要不会残留；查看摘要不会修改字段、随机池、锁或撤销历史。
- 加强异步导入保护：关闭面板、切换工作流、移除节点、重新载入配置或选择另一个文件后，迟到的旧读取不会写回。原同名确认、整包校验与原子写入规则保持不变。

卡片入口：右键节点 → **卡片管理 / 模块锁定**。卡片包使用 **导入卡片包**；“素材搜索与收藏 → 导入收藏”只接受素材收藏文件。

### 兼容与更新

- 保持 11 个节点、原端口、v1 卡片结构和工作流字段；不改变提示词、随机算法、种子或分辨率计算。没有新增依赖或在线服务。
- 现有 v0.15.0 卡片和工作流可继续使用。发型／姿态动作卡仍要求 v0.15.0 或以上；v0.16.0 不扩展卡片类型或容量。
- 文件上限仍为 1 MiB；保留各入口原有 BOM 策略和校验严格度。内容卡与拍摄方案的配额仍分别计算。
- 更新前保存工作流备份，避免同时启用多个安装副本；更新后重启 ComfyUI 并刷新页面。
- 下载本页附件 `ComfyUI-Z-Image-Prompt-Builder-v0.16.0.zip`，包内根目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，使用配套 `SHA256SUMS.txt` 核对下载文件。

验收包含中文 Classic、英文 Nodes 2.0、真实文件选择器、800×600 窄视口、独立发型节点及一次快捷组合应用／撤销／重做。未运行生图，不承诺所有宿主版本的全矩阵兼容。

详见[内容卡说明](../content-cards.md)、[拍摄方案说明](../shoot-plan-cards.md)、[快捷组合说明](../card-quick-combination.md)及[发布前验收记录](../testing/2026-11-05-v0.16.0-release-acceptance.md)。

## English

This release focuses on card usability: **find the right import entry and understand saved contents before applying a card.**

- Imports for material favorites, single content cards, content-card packs, Shoot Plan Cards and user presets identify the declared format. A wrong entry explains where to import it. The destination still validates the full contents; nothing is automatically converted or applied.
- Card management, Shoot Plan Cards and Quick Card Combination show read-only **Card contents** summaries. Content cards show key fields and explicit clearing notices; shoot plans distinguish included modules from those selected for application. Summaries are not exhaustive and do not replace differences or the complete field view.
- Refreshing lists, choosing **Keep Current**, or having no matching selection clears stale summaries. Reading contents does not change fields, random pools, locks or undo history.
- Asynchronous imports reject stale results after closing a panel, changing workflows, removing or reconfiguring a node, or selecting a later file. Existing conflict confirmation, whole-pack validation and atomic writes remain in place.

Card entry: node context menu → **Cards / Module Locks**. Use **Import Card Pack** for a card pack; **Search & Favorites → Import Favorites** accepts material-favorites files only.

### Compatibility and updating

- Still 11 nodes, existing ports, v1 card structures and workflow fields. Prompt output, randomization, seeds and resolution calculations are unchanged. No new dependencies or online services.
- Existing v0.15.0 cards and workflows remain supported. Hair / Pose Cards still require v0.15.0 or later; this release adds no card types or capacity.
- Files remain limited to 1 MiB. Existing per-entry BOM policies and strict validation remain unchanged. Content cards and shoot plans retain separate quotas.
- Back up workflows before updating, avoid duplicate active installations, restart ComfyUI and refresh the page.
- Download the attached `ComfyUI-Z-Image-Prompt-Builder-v0.16.0.zip`, with a fixed internal root of `ComfyUI-Z-Image-Prompt-Builder`, and verify it using the accompanying `SHA256SUMS.txt`.

Acceptance covered Chinese Classic, English Nodes 2.0, native file selection, an 800×600 viewport, the standalone Hair node and one real combination apply/undo/redo sequence. No images were generated; this is not a compatibility guarantee for every host version.
