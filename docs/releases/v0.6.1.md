# v0.6.1

## 中文

本次为提示词渲染与随机场景修复版本。保留 v0.6.0 的 TXT 随机抽取及 69 条扩展短语，节点数量仍为 11 个，不增加运行依赖或网络调用。

### 修复

- 场景字段设为“不使用”时，不再把省略值当作场景匹配条件，避免随机切入不相关场景；非跨风格随机先使用主题或预设场景，再回退到大类。明确地点／天气仍保持锁定。
- 精简英文与中文保留的信息对齐，修复人物、发型、服装材质与配饰、摄影和视觉字段漏写；原有密度裁剪、妆容／服装隐藏分支及近景鞋袜省略继续生效。
- 校正族裔英文冠词与大小写、12 个摄影媒介的译法及四类衣物图案词组，同步英文界面显示。
- 空白穿搭结构下，仅选颜色、材质或图案时，英文不再补出未指定的衣物类型。
- 用户模块句末的问号、感叹号等不再叠加句号；英文拼接识别中文标点；纯空白自由提示词不参与连续拼接。
- 详细中文服装保留完整材质描述，但去掉衣物名前的重复材质；区分穿搭配方的未收录属性与明确空池。
- 未知预设回退时记录警告，保留旧名称迁移；清理不可达路由并避免提前读取未使用的随机池。

### 兼容与验证

节点端口、保存字段、TXT 格式和分辨率算法不变。新节点默认分段，旧工作流未保存排版参数时仍连续拼接。十套固定预设的选项不变；英文输出及部分详细中文措辞按上述修正规则变化。随机候选优先级修正后，同一种子的场景可能与旧版本不同，同一版本内仍可复现。

干净发布文件集通过 **177 项 Python 测试、19 套前端测试、11 个 JavaScript 文件语法检查及 9 次隔离 CPU 纯文本执行**，包括新增的 18 项审核回归。翻译与分辨率目录重新生成后逐字节一致。本轮没有重新进行真实浏览器点选或实际生图；自动前端测试不等于实机界面验收，也不保证模型严格遵循每个词句。逐项审核见 [测试记录](../testing/2026-09-30-deepseek-review.md)。

### 安装

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.6.1.zip**，解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，无需改名；使用同页的 **SHA256SUMS.txt** 校验安装包。先备份工作流和自定义词库，避免同时启用多个副本。Git 安装可在节点目录运行 `git pull --ff-only`。

更新文件不会让运行中的 ComfyUI 自动加载新代码。请重启 ComfyUI，并按 **Ctrl+F5** 刷新浏览器。

## English

This patch release fixes prompt rendering and random scene selection. It retains v0.6.0's seeded TXT selection and 69 constrained phrases. The package still registers 11 nodes, with no added runtime dependencies or network calls.

### Fixes

- Disabled scene fields no longer act as literal scene-matching constraints. Non-cross-style sampling prefers theme or preset scenes before category fallbacks, while explicit location and weather choices remain locked.
- Concise English preserves the information retained by Chinese, correcting missing person, hair, clothing fabric/accessory, camera and visual details. Existing density trimming, hidden makeup/clothing branches and close-up legwear omissions remain in effect.
- Corrected ethnicity articles and capitalization, all 12 capture-medium translations and garment-pattern phrases across four clothing branches; regenerated English UI labels.
- With an unspecified outfit structure, isolated color, fabric or pattern selections no longer invent an unselected garment type in English.
- User-module question and exclamation marks no longer receive an extra period. English joins recognize Chinese punctuation, and whitespace-only free text is ignored in continuous output.
- Detailed Chinese clothing describes fabric once while retaining its full description. Recipe selection distinguishes an uncurated property from an explicitly empty pool.
- Unknown presets log a fallback warning without breaking legacy-name migration. Unreachable routing and eager reads of unused random pools were removed.

### Compatibility and verification

Ports, saved field identifiers, TXT formats and resolution arithmetic are unchanged. New nodes default to paragraphs; legacy workflows with no layout parameter still use continuous output. The ten fixed presets retain their selections, with the English output and some detailed Chinese wording corrected as described above. Scene-pool priority changes can alter an older version's seeded result; results remain reproducible within the same version.

The clean publication file set passed **177 Python tests, 19 frontend suites, syntax checks for 11 JavaScript files and 9 isolated CPU text executions**, including 18 new review regressions. Regenerated translation and resolution catalogs were byte-identical. This round did not repeat live browser interaction or generate images; automated frontend tests are not a substitute for real UI acceptance or a guarantee of model output. See the [review record](../testing/2026-09-30-deepseek-review.md).

### Installation

Download **ComfyUI-Z-Image-Prompt-Builder-v0.6.1.zip** and extract into `ComfyUI/custom_nodes`. Its root is already named `ComfyUI-Z-Image-Prompt-Builder`. Verify the archive using **SHA256SUMS.txt**. Back up workflows and custom libraries first and avoid multiple enabled copies. Git installations can run `git pull --ff-only` in the node directory.

Updating files does not reload a running ComfyUI process. Restart ComfyUI and refresh the browser with **Ctrl+F5**.
