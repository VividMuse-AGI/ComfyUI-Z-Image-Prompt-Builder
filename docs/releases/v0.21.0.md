# v0.21.0

## 中文

**切回工作流，不用重跑就能找回上次的提示词。** 在支持此功能的前端，运行工作流 A 后切到 B，再切回仍打开的 A。打开完整节点或任一独立标准模块的 **查看结果**，即可找回该节点最近一条成功结果。中英文正文、换行、实际种子和执行标识均保留。

- 不切换时仍可查看最多五条；切换后只恢复最新一条。关闭后台工作流不会清掉其他工作流正在执行的结果。
- 恢复的记录可复制或通过 **更多… → 导出结果 JSON** 保存。如需保存为卡片，请先运行当前节点。
- 记录仅保存在当前页面内存。刷新、关闭后重开、另存副本、删除后重建或撤销删除不会继承旧记录；切走后才结束的任务不补录。两个独立 TXT 节点和子图内节点不参与恢复。
- 没有所需接口或无法确认归属时，沿用原行为，仍可运行节点、复制和导出当前会话的结果。经典界面和 Nodes 2.0 已在 ComfyUI 0.46.0／前端 1.59.6 实测；官方 Desktop 未独立验收。工作流格式、节点端口和结果导出格式不变，无需迁移。

手动更新请使用本页附件 `ComfyUI-Z-Image-Prompt-Builder-v0.21.0.zip` 和 `SHA256SUMS.txt`。安装包内根目录为 `ComfyUI-Z-Image-Prompt-Builder`。更新后重启 ComfyUI 并用 Ctrl+F5 刷新浏览器。[中文使用说明](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.21.0/README.md)

## English

**Return to a workflow and recover the last prompt without rerunning.** On a supported frontend, run workflow A, switch to B, then return to the still-open A. Open **View Results** on the full builder or any standalone standard module to recover that node’s latest successful result, including the original Chinese and English text, line breaks, actual seed and execution ID.

- Up to five results remain available without switching; only the latest one is restored after switching. Closing a background workflow no longer discards results pending for another workflow.
- Copy the restored text or use **More… → Export Result JSON**. To save a card, run the current node again first.
- Results stay in the current page’s memory. Refreshing, closing and reopening a workflow, saving a copy, or recreating a node (including undoing deletion) does not restore its old record. Jobs that finish while you are away are not added retroactively. The two standalone TXT nodes and nodes inside subgraphs do not use this feature.
- If required frontend capabilities are missing or result ownership cannot be confirmed, existing behavior remains available: you can still run, copy and export results in the current session. Tested in Classic and Nodes 2.0 on ComfyUI 0.46.0 / frontend 1.59.6; the official Desktop app was not tested separately. Workflow formats, ports and result exports are unchanged. No migration is needed.

For a manual update, download the attached `ComfyUI-Z-Image-Prompt-Builder-v0.21.0.zip` and verify it with `SHA256SUMS.txt`. The archive’s root folder is `ComfyUI-Z-Image-Prompt-Builder`. Restart ComfyUI and force-refresh the browser with Ctrl+F5 after updating. [English guide](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.21.0/README.en.md)
