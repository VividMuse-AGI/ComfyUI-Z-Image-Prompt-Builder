# v0.17.0

2026-11-06

## 中文

本版聚焦一个问题：**种子变了，为什么提示词可能没变？**

### 更新内容

- 在原“实际执行结果”面板分开显示当前配置和所选历史执行。当前随机、指定值、跟随预设和不使用分别计数；锁定仅说明当前随机按钮保护，解锁不会自动启用随机。
- 对已统计的场景、摄影、光线、配色／质感采样环节，显示候选条目数与实际随机字段对应的不同组合数。只有一种组合时说明重复的原因；多条候选也可能重复命中。
- 区分早期抽取、后续已覆盖和联动后重抽，不把过期采样当作最终结果。尚未统计的字段明确标记；不会编造全模块组合数或概率。
- 两个独立 TXT 节点解释当前历史记录中的零条、单条、多条候选，保留原抽取范围、实际种子、手动草稿和导出格式。

入口：运行完整节点或标准模块 → 点击“查看上次结果”。TXT 节点使用原“上次随机结果”入口。无需启用随机也能查看固定配置说明；修改或运行后重新打开面板以刷新。

### 兼容与限制

- 保留 11 个节点、原端口、工作流字段、卡片与结果导出格式，不新增画布常驻控件或依赖，也不调用在线服务。
- 不改变词库、随机候选顺序、随机数消耗、提示词、分段、分辨率和同输入同种子结果；本版不是随机内容扩充或组合一致性修复。
- 光线和配色／质感各自统计；单步数量不能相乘当作完整模块的总组合数。上游随机上下文变化时，候选也可能变化。
- 旧执行数据缺少新说明时正常降级。历史只在当前页面会话保留，不写入工作流；宿主自身可能保存执行 UI 数据。
- 更新前备份工作流，避免重复安装；更新后重启 ComfyUI 并刷新页面。

功能回归及中英文、Classic／Nodes 2.0 代表界面已验收。没有运行生图，也不承诺所有宿主版本、屏幕尺寸或随机组合的完整覆盖。紧凑说明字号仍可进一步改善。

## English

This release focuses on one question: **Why can the prompt stay the same after the seed changes?**

### Changes

- The existing Actual Execution Results panel separates current settings from the selected historical execution. Random, fixed, preset-following and omitted fields are counted separately. Current lock protection is not used to explain historical results; unlocking does not enable random sampling.
- Instrumented scene, camera, lighting and color/finish sampling steps show candidate-entry counts and distinct combinations of the active random fields. One combination can explain repetition; multiple candidates still permit repeated selections.
- Initial draws, overwritten steps and later redraws are distinguished. Unmeasured fields are identified explicitly, without inventing whole-module counts or probabilities.
- Both standalone TXT nodes explain zero, one or multiple candidates in the selected historical result while preserving scope, submitted seed, manual drafts and export formats.

Open the full builder or a standard module, run it, then click Last result. TXT nodes retain their Last Random Result entry. Fixed configurations can be inspected without enabling randomization. Reopen the panel after editing or running to refresh its snapshot.

### Compatibility and limitations

- Still 11 nodes, existing ports, workflow fields, card and result-export formats. No new permanent canvas controls, dependencies or online services.
- No changes to libraries, candidate order, random-number consumption, prompt output, paragraph layout, resolution or deterministic results. This release does not expand random content or fix semantic consistency across all combinations.
- Lighting and color/finish are counted separately. Do not multiply step counts into a whole-module total. Randomized upstream context can change the candidates.
- Older execution records without the new metadata degrade gracefully. History is session-only and not serialized into workflows; the host may retain execution UI data separately.
- Back up workflows before upgrading, avoid duplicate installations, restart ComfyUI and refresh the page afterward.

Functional regressions and representative Chinese/English, Classic/Nodes 2.0 UI checks passed. No images were generated, and coverage is not exhaustive across host versions, screen sizes or random combinations. The compact explanation typography remains a possible usability improvement.
