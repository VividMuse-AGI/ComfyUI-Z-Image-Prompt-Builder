# v0.9.0

## 中文

本次新增搜索反馈、实际结果快照导出和可选构图适配，节点总数仍为 11 个。

- **搜索更方便**：25 组中英文别名、匹配数量、空词库／空模块／无匹配提示，以及收藏导入的新增、重复、匹配统计。修复空 TXT 模块误显示整库的问题。
- **结果可保存**：完整节点和八个模块可选择最近五次执行、复制中英文并导出 JSON 内容快照。记录实际种子和解析字段，不受下一次种子影响；历史仅存内存。两个 TXT 节点的随机结果弹窗不含此导出。
- **构图适配**：完整节点、服装和姿态模块新增默认关闭的开关。启用后按明确景别省略画外的独立下装、鞋袜和腿部动作，不清空原选项、不重新随机。坐姿半身保留下装和腿部动作，仅省略鞋袜；全身不额外省略。
- **兼容优先**：旧工作流默认保持原规则，端口和随机池不变，无新增 Python 依赖或在线服务。独立模块需上游明确摄影上下文；复合动作、连体服、版型细节及用户 TXT／自由文本不强行拆解。

### 使用与安装

运行完整节点或标准模块后，点击节点内“随机 0 项 · 查看上次结果”（数字可能不同），在弹窗点击“导出此结果”。导出是内容快照，不是工作流，也不能作为用户预设导入。

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.9.0.zip**，使用 **SHA256SUMS.txt** 校验，解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`。Git 安装可执行 `git pull --ff-only`；更新后重启 ComfyUI 并刷新浏览器。请先备份本地修改，勿同时保留多个有效安装副本。

### 验证

公开范围包含 195 项 Python 测试、22 组前端回归、15 个 JS 语法检查及三份生成目录检查。完成 ComfyUI 0.42.4 下中英文／经典／Nodes 2.0 代表操作、保存重开、7 次纯文本执行和用户实际导出文件核对；未生图。正式附件仅在发布 CI 通过后生成。[完整验收范围与限制](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.9.0/docs/testing/2026-10-22-v0.9.0-acceptance.md)。

## English

This release improves search feedback, adds actual-result snapshot export, and introduces opt-in framing adaptation. The package still has 11 nodes.

- **Search feedback:** 25 bilingual alias groups, match counts, distinct empty states, and favorite-import added/duplicate/matched counts. Empty TXT modules no longer fall back to the entire library.
- **Reusable results:** the full builder and eight standard modules offer the latest five execution records, Chinese/English copy, and JSON content snapshots. Records preserve actual seeds and resolved fields, independent of the next seed. History is memory-only. The two TXT random-result dialogs do not offer this export.
- **Framing adaptation:** an optional, default-off control in the full builder, Clothing and Pose modules. Explicit close framing omits independent lower-garment, legwear, footwear and leg-action fields without clearing selections or rerolling. Seated-half framing omits only legwear and shoes; full-body framing adds no omissions.
- **Compatibility:** legacy workflows keep existing rules; ports and random pools remain unchanged. No new Python dependencies or online calls. Standalone adaptation requires explicit upstream camera context; compound actions, dresses/bodysuits, fit details, free text and TXT content are not forcibly split.

### Use and installation

Run the full builder or a standard module, click **Random: 0 fields · Last result** (the count may vary), then **Export This Result**. Exported JSON is content only, not an executable workflow or importable user preset.

Download **ComfyUI-Z-Image-Prompt-Builder-v0.9.0.zip**, verify **SHA256SUMS.txt**, and extract into `ComfyUI/custom_nodes`. The archive has the fixed root `ComfyUI-Z-Image-Prompt-Builder`. Git installations can use `git pull --ff-only`. Back up local edits, avoid duplicate active installations, restart ComfyUI, and refresh the browser.

### Verification

The public scope includes 195 Python tests, 22 frontend suites, 15 JavaScript syntax checks, and three generated-catalog checks. Representative Chinese/English and Classic/Nodes 2.0 cases passed on ComfyUI 0.42.4, including save/reopen, seven text-only executions, and a user-downloaded snapshot matched against execution history. No images were generated. Official assets are built only after release CI passes. See the [acceptance scope and limitations](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.9.0/docs/testing/2026-10-22-v0.9.0-acceptance.md).
