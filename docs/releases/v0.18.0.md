# v0.18.0

2026-11-07

## 中文

本版新增可选的“协调优先”，减少两类有明确字段依据的随机组合冲突。默认组合继续使用原行为。

### 使用方式

1. 在完整节点、独立姿态动作或场景节点中，将需要变化的字段设为“随机抽取”。
2. 将“组合协调”设为“协调优先”，运行节点。
3. 打开“查看上次结果”，查看实际模式、调整前后值或保留原因。只开启协调不会自动开启随机。

当前覆盖“盘腿而坐与高脚椅横杆腿部动作”和“泳池边坐姿与校园教室”两个明确组合。例如指定教室、基础姿态随机时，可从原候选池选择自然站立替代泳池边坐姿；固定盘腿但原池没有可靠腿部替代时，保留原结果并明确提示无可用候选。

### 兼容与边界

- 新设置仅追加到三个节点。旧工作流未提供此输入时使用默认组合，保持原输出；11 个节点和既有输出端口不变。
- 协调只修改当前节点允许随机变化的内置字段，不改指定值、跟随预设或上游输出，不扩大候选池、解锁或改种子。切换模式可能改变同种子结果；同版本、相同输入、模式和种子可复现。
- 自由提示词和 TXT 原文保留，不用自然语言猜测场景；相关规则遇到不完整上下文时保守跳过。无可靠替代时保留并说明，不宣称冲突已经解决。
- 独立模块分别设置模式，只读取已收到的结构化上下文。建议场景→姿态动作→摄影；反向链可以适配自己的字段，但不能回写上游，也不保证不同顺序结果相同。
- 协调说明对应最终输出，不自动修改下拉框或保存卡片。卡片和结果导出格式不变，工作流保存新增模式。
- 不扩充词库、规则覆盖以外的搭配或人体模型，不保证生成图片姿态正确；不新增依赖、在线服务或生图步骤。

结果面板同时修复中英文禁用说明的重复模块名，抽取与协调说明改为 14px、1.6 倍行距，保留滚动区域而非撑长节点。

### 安装

下载本页附件 `ComfyUI-Z-Image-Prompt-Builder-v0.18.0.zip`，包内根目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，使用 `SHA256SUMS.txt` 核对文件。更新前备份工作流，避免重复安装；更新后重启 ComfyUI 并刷新页面。安装步骤见 [README](../../README.md)。

## English

This version adds optional Coherence First to reduce two explicit conflicts between structured random selections. Standard keeps existing behavior.

### Usage

1. On the full builder, standalone Pose or Scene node, set the fields you want to vary to Random.
2. Set Combination Coherence to Coherence First and run the node.
3. Open Last result to inspect the executed mode, before/after values or retention reasons. Enabling coherence does not enable randomization.

Initial coverage includes sitting cross-legged with a stool-rung leg action, and a poolside seated pose in a campus classroom. With a fixed classroom and random base pose, an eligible standing pose can replace the poolside pose. If the original pool has no reliable leg-action replacement for a fixed cross-legged pose, the original result remains and the absence of an eligible candidate is reported.

### Compatibility and boundaries

- The setting is appended only to these three nodes. Legacy workflows without it use Standard and preserve prior output. The package still has 11 nodes with unchanged existing output ports.
- Only eligible built-in random fields owned by the current node may change. Explicit selections, preset-following values and upstream output remain intact. Candidate scope, locks and seed are not expanded or rewritten. Switching modes may change same-seed results; identical version, inputs, mode and seed are reproducible.
- Free text and TXT content remain verbatim; natural-language context is not inferred. Relevant rules skip incomplete context conservatively. No reliable replacement means retention with an explanation, not a claim that the conflict was resolved.
- Each module chooses its own mode and uses only received structured context. Scene → Pose → Camera is recommended. Reverse chains can adapt their own fields but cannot rewrite preceding output or guarantee order-independent results.
- Explanations describe final output without changing dropdowns or saving cards automatically. Card and result-export formats are unchanged; workflows save the new mode.
- No library expansion, general semantic/anatomy guarantee, new dependency, online service or image-generation step.

The result panel also removes duplicated module prefixes from bilingual unavailable-card messages. Sampling and coherence details use 14px text with 1.6 line height while retaining bounded scrolling.

### Installation

Download the attached `ComfyUI-Z-Image-Prompt-Builder-v0.18.0.zip`, with a fixed internal root of `ComfyUI-Z-Image-Prompt-Builder`, and verify it using `SHA256SUMS.txt`. Back up workflows, avoid duplicate installations, restart ComfyUI and refresh the page after updating. See the [README](../../README.en.md) for installation steps.
