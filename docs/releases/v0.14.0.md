# v0.14.0

## 中文

本次新增**卡片快捷组合**，在完整节点内一次组合人物卡、穿搭卡和拍摄方案卡。

- 三类卡片默认“保持当前”；拍摄方案可只应用场景、摄影或视觉表现中的部分模块。
- 各模块独立选择“保留当前锁定”或“应用后锁定此模块”。先预览来源、字段差异和新增锁定，再确认应用。
- 一次撤销／重做覆盖整次应用。已连接输入、TXT 替代和过期预览会阻止应用，避免部分写入。
- 不改变未选模块、自由提示词、种子、比例、分辨率、发型和动作。关闭后不记住临时选择，不自动随机或运行生图。

入口：完整节点右键 → **卡片管理 / 模块锁定** → **卡片快捷组合**。先在原管理面板保存或导入卡片；独立模块节点继续使用原卡片入口。人物卡不包含发型；“保留当前锁定”不是解锁。

保持 11 个节点、现有端口、v1 卡片格式及容量，不新增依赖或在线服务。详见[使用说明](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.14.0/docs/card-quick-combination.md)。

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.14.0.zip** 并核对 **SHA256SUMS.txt**，解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`；避免同时启用多个副本。Git 安装先备份本地修改再更新。重启 ComfyUI 并刷新页面。

中文 Classic、英文 Nodes 2.0、真实撤销／重做、保存重开、TXT 阻断及人工体验审核通过。测试范围见[发布验收](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.14.0/docs/testing/2026-11-04-v0.14.0-release-acceptance.md)。未运行生图或评估图像质量。

## English

**Quick Card Combination** brings Person, Outfit and Shoot Plan Cards together in one panel on the full builder.

- All three selectors default to **Keep Current**. Apply only the Scene, Camera or Visual modules you need from a Shoot Plan Card.
- Choose **Preserve Current Locks** or **Lock Module After Applying** per module. Preview sources, field differences and new locks before confirming.
- One undo/redo covers the entire application. Connected inputs, TXT replacements and stale previews block application instead of allowing partial writes.
- Unselected modules, free text, seed, ratio, resolution, hair and pose remain unchanged. Closing discards temporary choices; no automatic randomization or image generation occurs.

Entry: full builder context menu → **Cards / Module Locks** → **Quick Card Combination**. Save or import cards using the existing panels first. Standalone module nodes retain their existing card actions. Person Cards exclude hair; preserving locks does not unlock fields.

The package retains 11 nodes, existing ports, v1 card formats and quotas, with no new dependencies or online services. See the [guide](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.14.0/docs/card-quick-combination.md#english).

Download **ComfyUI-Z-Image-Prompt-Builder-v0.14.0.zip**, verify **SHA256SUMS.txt**, and extract into `ComfyUI/custom_nodes`. The internal root is `ComfyUI-Z-Image-Prompt-Builder`; avoid duplicate active installations. Back up local edits before updating a Git installation. Restart ComfyUI and refresh the page.
