# v0.20.0

2026-11-10

## 中文

本版简化查看、复制、复用和清空提示词的操作，同时增加两个精确手动动作。专业控制继续保留，不新增简单／专业模式。

### 更新内容

- **结果正文优先**：完整节点与独立模块的入口统一为“查看结果”。中英文正文及复制按钮前置，导出结果 JSON 和手动复制位于“更多…”，卡片保存、随机说明与技术详情默认折叠。两个 TXT 节点使用“查看抽取结果”，明确区分抽中条目与最终组合文本。
- **统一预设与卡片管理**：节点右键菜单中的“我的预设与卡片”提供整套预设、模块卡片和组合应用；独立节点只显示支持的功能。随机锁定与组合检查另列在“随机设置与检查”，不增加节点常驻高度。
- **明确随机与清空**：“设置随机组合／设置本模块随机”准备字段，运行节点后才产生结果。完整节点通过“清空内容…”选择结构化或全部提示词并确认；“仅启用当前模块”会在其他模块有内容时确认清除范围。自由提示词旁保留直接清空入口，移除 TXT 词库与清空已应用文本使用不同名称。
- **两个精确手动动作**：新增“一手轻扶翻领”“一手轻扶领口边缘”，支持中英文、提示词密度和姿态卡。旧“一手轻扶衣领”保持原含义，新动作不加入现有内置随机池。
- **双语使用说明**：首页突出安装和最短使用流程，详细手册保留兼容说明；补充经典与 Nodes 2.0 实机截图。测试采用固定 v0.19.0 随机准备快照，不再依赖会随提交移动的 HEAD。

### 使用与兼容边界

- 保留 11 个节点、现有端口、序列化字段名、卡片／收藏／结果导出格式；界面标签变化不要求重建旧工作流。含新增手动动作的工作流或卡片需要本版支持。
- 原有随机池及随机准备语义不变。仅改变种子不会将固定字段变为随机，随机也不保证每次不同。应用卡片、显式清空和手动修改保持既有权限，不受随机锁定一概禁止。
- 清空结构化内容保留自由提示词，清空全部提示词同时移除自由文本；两者均保留已导入词库。画面比例会被清空，像素预算等计算设置保留，不承诺最终宽高保持不变。
- 两个新动作需要用户匹配服装结构，不自动换衣、不解析上游自然语言，也不是新增通用服装纠错功能。
- TXT 和用户自由文本保留原文，不自动翻译。结果导出是只读快照，不是可执行工作流；完整节点与标准模块保留最近五次内存记录，TXT 节点保留上次抽取记录，刷新后可能清空。运行后重新打开面板查看新结果。
- 复制提示表示已发送请求；若系统粘贴未更新，可从“更多…”使用对应语言的手动复制。无新增依赖、在线服务或生图步骤。

### 安装与更新

下载附件 `ComfyUI-Z-Image-Prompt-Builder-v0.20.0.zip`，包内根目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，使用 `SHA256SUMS.txt` 核对。更新前备份工作流和个人词库，避免保留重复安装副本；更新后重启 ComfyUI，并按 Ctrl+F5 刷新浏览器。[中文使用说明](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.20.0/README.md)。

## English

This release simplifies viewing, copying, reusing and clearing prompts, and adds two precise manual hand actions. Existing controls remain available without adding simple or advanced modes.

### Changes

- **Text-first results**: the full builder and standalone modules use **View Results**. Chinese and English text and copy actions come first. **More…** contains JSON export and manual-copy options; card saving, randomness explanations and technical details start collapsed. TXT nodes use **View Draw Result**, distinguishing the selected entry from combined output.
- **Unified saved content**: right-click a node to open **My Presets & Cards**, with Whole Presets, Module Cards and Apply Combination where supported. Standalone nodes expose only their supported features. Locks and combination checks are under **Random Settings & Checks**, without additional permanent node height.
- **Clearer random and clear actions**: **Set Up Random Combination / Set Up Module Randomness** prepares fields; Run produces the result. **Clear Content…** lets users choose structured or all prompt content and confirm its scope. **Enable Only This Module** asks for confirmation when other modules contain content. Free Prompt has a nearby clear action, and removing TXT libraries is distinguished from clearing applied text.
- **Two precise manual actions**: a hand lightly touching a fold-over collar or the neckline edge, with bilingual output, density variants and pose-card support. The existing collar action is unchanged. Neither new action is added to existing built-in random pools.
- **Bilingual documentation**: task-first READMEs, detailed compatibility guidance and real classic/Nodes 2.0 screenshots. Random-preparation regression tests use fixed v0.19.0 snapshots instead of a moving Git HEAD.

### Usage and compatibility

- All 11 nodes, existing ports, serialized field names and card/favorite/result-export formats remain available. Display-label changes do not require rebuilding workflows. Workflows or cards using the new manual actions require this version.
- Existing random pools and preparation behavior are unchanged. Changing the seed does not enable randomization for fixed fields, and repeated results remain possible. Random locks do not universally prevent manual editing, explicit clearing or card application.
- Clearing structured content keeps Free Prompt; clearing all prompt content removes it too. Both retain imported libraries. Aspect Ratio is cleared while pixel-budget calculation settings remain, so final output dimensions may change.
- Match the new hand actions to appropriate clothing yourself. They do not change outfits, interpret upstream natural language or provide general clothing-conflict correction.
- TXT and free text remain verbatim without automatic translation. Result exports are read-only snapshots, not executable workflows. The full builder and standard modules keep the latest five execution records in memory; TXT nodes keep the last draw record. Records may clear on refresh; reopen the panel after running for the latest result.
- Copy status reports a submitted request. If system paste remains stale, use the matching manual-copy action under **More…**. No new dependency, online service or image-generation step is required.

### Installation and updating

Download `ComfyUI-Z-Image-Prompt-Builder-v0.20.0.zip` and verify it using `SHA256SUMS.txt`. Its internal root remains `ComfyUI-Z-Image-Prompt-Builder`. Back up workflows and personal libraries, avoid duplicate installations, then restart ComfyUI and force-refresh the browser with Ctrl+F5. See the [English guide](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.20.0/README.en.md).
