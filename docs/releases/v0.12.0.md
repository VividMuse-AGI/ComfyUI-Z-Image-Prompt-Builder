# v0.12.0

## 中文

本版聚焦 **拍摄方案卡**：把场景、摄影和视觉表现保存为可选择应用的组合，方便保留灯光与机位，同时替换人物或穿搭。

- **两种保存来源**：当前配置，或实际执行结果面板中选中的历史记录。跟随预设解析成具体值；未解析随机字段需先执行。保存不重抽、不自动应用或锁定。
- **按模块复用**：应用前核对差异，只有勾选模块被覆盖；“不使用”也作为完整快照保存。应用并锁定会追加目标字段的随机锁，不移除其他锁。手动应用仍可更新已锁字段。
- **单卡和卡片包**：JSON 导入先完整校验，再预览新增、覆盖、跳过和不适用项；默认跳过同名，替换需确认。独立节点只应用自身模块，但保存和导出完整组合卡。
- **保护与兼容**：连接输入、TXT 替换、不完整历史及场景依赖冲突会明确提示。预览过期或节点会话变化不能继续写入。原人物／穿搭卡及其格式保持独立。

### 入口与限制

右键完整节点或场景／摄影／视觉表现独立节点 → **卡片管理 / 模块锁定** → **拍摄方案卡**。保存后请保存工作流。

每节点最多 100 张拍摄方案卡，与人物／穿搭卡分别计数；名称最多 80 个 UTF-16 单位；文件最大 1 MiB，卡包包含 1–100 张。灯光属于视觉表现。卡片不包含人物、穿搭、动作、自由文本、画幅、分辨率或种子；不保证同一人物或图片一致。执行结果 JSON、工作流和卡片是不同格式。

保留 11 个节点和现有端口，无新增依赖、在线服务或生图步骤。已有工作流无须迁移；旧执行记录需重新运行才能得到新的拍摄候选数据。

## English

This release introduces **Shoot Plan Cards**: reusable combinations of Scene, Camera and Visual settings, with selective application. Keep lighting and camera settings while changing a person or outfit.

- **Two capture sources:** current settings or a selected actual execution record. Follow Preset resolves to concrete values; unresolved Random fields require an execution first. Saving does not reroll, apply or lock anything.
- **Selective application:** preview differences and replace only checked modules, including explicit unused values. Apply & Lock adds target fields to random locks without removing existing locks. Explicit card application may still update locked fields.
- **Cards and packs:** validate the whole JSON file before previewing additions, replacements, skipped names and inapplicable cards. Existing names are skipped by default; replacement requires confirmation. Standalone nodes apply only their own module while retaining and exporting the entire card.
- **Safety and compatibility:** linked inputs, TXT replacements, incomplete history and incompatible scene dependencies show reasons. Stale previews and changed node sessions cannot write back. Existing Person / Outfit Cards keep their separate format.

### Entry point and limits

On the full builder or Scene / Camera / Visual node, use the context menu → **Cards / Module Locks** → **Shoot Plan Cards**. Save the workflow afterward.

Up to 100 shoot plan cards per node, separate from person/outfit cards; names up to 80 UTF-16 code units; files up to 1 MiB; packs contain 1–100 cards. Lighting belongs to Visual. Cards exclude person, outfit, pose, free text, canvas, resolution and seed. They do not guarantee identity or identical images. Result JSON, workflows and cards are different formats.

The package retains 11 nodes and existing ports, without new dependencies, online services or image-generation steps. Existing workflows need no migration; older execution records require another run to supply shoot-plan candidates.
