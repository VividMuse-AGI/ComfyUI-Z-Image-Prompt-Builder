# v0.7.0

## 中文

本次新增“随机状态与执行结果”面板，并修复现代前端保存工作流时可能出现的字段错位。节点数量仍为 11 个。

### 新功能与修复

- 完整节点和八个独立模块增加紧凑的只读结果入口，显示实际提交种子、解析字段、中英文正文及模块变化，方便判断随机设置是否生效。
- 最近五次执行保存在内存中；面板区分当前设置与上次执行结果，支持缓存回显。输入框中的下一次种子不会替代已执行种子。
- 按提交时的工作流、节点实例和任务编号关联结果，避免切图、删除节点或延迟结果造成串用；连接输入以实际执行值为准。
- 修复现代前端对已经压缩的保存数组再次过滤，导致字段错位的问题，覆盖完整节点、八个模块和两个 TXT 节点。已经损坏的旧文件不会自动猜测恢复。
- 补充双语界面说明、保存恢复和诊断回归，兼容旧宿主的纯文本验收脚本。

### 使用与兼容

Run 只抽取已设为“随机抽取”的字段。指定值、跟随预设和不使用保持各自语义；改变种子不会自动开启随机。详情是打开时的快照，运行或编辑后重新打开即可查看最新记录。

诊断历史不写入工作流，但 ComfyUI 自身的执行历史可能保存返回的 UI 数据。未知来源任务，以及多个实例共享同一个内部节点对象的子图，不显示诊断；提示词输出仍可正常使用。

提示词端口、随机算法、词库、TXT 格式和分辨率计算保持兼容，没有新增运行依赖或网络调用。

### 验证

已验收运行代码通过 187 项 Python 测试、21 组前端回归和 12 个 JavaScript 文件语法检查。真实界面补测覆盖经典／Nodes 2.0 删除撤销、固定种子复现、快速提交与诊断对应，以及 ComfyUI 0.31.1／前端 1.48.7 的运行、缓存和保存重开。当前宿主实测为 ComfyUI 0.39.0／前端 1.53.10。发布流程在 Python 3.10／Node 22 CI 通过后才生成正式附件。

范围与限制见[验收记录](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.7.0/docs/testing/2026-10-07-focused-release-acceptance.md)。本轮使用纯文本工作流，没有生图。

### 安装

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.7.0.zip**，用同页 **SHA256SUMS.txt** 校验后解压到 `ComfyUI/custom_nodes`。内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`。Git 安装可在节点目录执行 `git pull --ff-only`。更新后重启 ComfyUI 并刷新浏览器。

## English

This release adds the Random Status and Execution Result panel and fixes shifted widget values when workflows are saved by modern frontends. The package still contains 11 nodes.

### Features and fixes

- The full builder and eight standalone modules gain a compact read-only panel showing the submitted seed, resolved fields, Chinese/English output and changed modules.
- The last five executions remain in memory. The panel distinguishes current settings from the last result and supports cached execution data. The editor's next seed does not replace the seed used by an earlier job.
- Results are associated with the submitted workflow, node instance and job ID, preventing delayed responses from being assigned to another workflow or a deleted node. Connected inputs use executed values.
- Fixed repeated filtering of already compacted widget arrays, which could shift saved values in modern frontends. The fix covers the full builder, eight modules and both TXT nodes. Previously damaged workflows are not reconstructed by guesswork.
- Added bilingual guidance, serialization and diagnostic regressions, and compatibility with older host constructors in the text-only acceptance scripts.

### Usage and compatibility

Run samples only fields set to Random. Fixed values, Follow Preset and Omit retain their meanings; changing a seed does not enable random fields. The details panel is a snapshot. Reopen it after executing or editing to see the latest record.

Diagnostic history is not serialized into workflows, but ComfyUI may retain returned UI data in its execution history. Diagnostics are omitted for unassociated jobs and subgraphs whose instances share a single internal node object; prompt output remains usable.

Prompt ports, sampling algorithms, phrase libraries, TXT formats and resolution calculations remain compatible. No runtime dependencies or network calls were added.

### Verification

The accepted runtime passed 187 Python tests, 21 frontend suites and syntax checks for 12 JavaScript files. Live UI follow-up covered Classic/Nodes 2.0 deletion and undo, seed reproducibility, rapid submissions matched to diagnostics, and execution, caching and saved-workflow reopening on ComfyUI 0.31.1 / frontend 1.48.7. The current host was ComfyUI 0.39.0 / frontend 1.53.10. The release workflow creates official assets only after Python 3.10 / Node 22 CI passes.

See the [acceptance record](https://github.com/VividMuse-AGI/ComfyUI-Z-Image-Prompt-Builder/blob/v0.7.0/docs/testing/2026-10-07-focused-release-acceptance.md) for scope and limitations. This round used text-only workflows without generating images.

### Installation

Download **ComfyUI-Z-Image-Prompt-Builder-v0.7.0.zip**, verify it with **SHA256SUMS.txt**, and extract it into `ComfyUI/custom_nodes`. The archive root is already named `ComfyUI-Z-Image-Prompt-Builder`. Git installations can run `git pull --ff-only` in the node directory. Restart ComfyUI and refresh the browser after updating.
