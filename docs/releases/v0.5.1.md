# v0.5.1

## 中文

本次更新简化分辨率设置，不改变提示词内容或输出端口顺序。

- 尺寸菜单仅保留 **保持比例计算（推荐）** 与 **按像素计算**，不再提供“推荐尺寸”选项。
- 分辨率相关界面按功能命名，不再用“新”“旧”区分计算方式。
- 已有工作流仍保留保存的固定尺寸；只有明确选择计算方式或修改 MP／整除倍数后，才重新计算。
- 修复英文 Nodes 2.0 中“使用已保存尺寸”状态未翻译的问题；中文、英文切换不会修改保存值或输出尺寸。
- 同步更新中英文 README、节点帮助和回归测试。

### 验证

- 完整节点和独立画面基础节点已完成隔离浏览器检查：Nodes 2.0 中英文下拉、实际切换及固定尺寸保存恢复通过；经典模式的中英文选项和紧凑布局通过。
- 自动回归覆盖尺寸算法、工作流兼容、双语界面、TXT 词库、模块串联及发布包完整性。
- 检查未运行生图，不改变用户工作流或设置。

### 安装与升级

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.5.1.zip**，解压到 `ComfyUI/custom_nodes`。安装包内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`，无需改名。升级前备份工作流和自定义词库，不要同时保留多个启用的节点副本。

Git 安装用户在节点目录运行 `git pull --ff-only`。升级后重启 ComfyUI，并按 **Ctrl+F5** 刷新浏览器。可使用 **SHA256SUMS.txt** 核对安装包。

## English

This patch simplifies resolution settings without changing prompt content or output-port order.

- The menu now offers only **Preserve Aspect Ratio (Recommended)** and **Calculate from Pixels**. Fixed recommended dimensions are no longer a selectable mode.
- Resolution controls use functional names rather than version-history terminology.
- Existing workflows retain their saved fixed dimensions until a calculation method is explicitly selected or MP / Divisible By is edited.
- Fixed the untranslated **Use Saved Dimensions** status in English Nodes 2.0. Language switching does not change saved values or output dimensions.
- Updated both READMEs, node help, and regression coverage.

### Verification

The full builder and standalone Canvas node passed isolated browser checks for bilingual Nodes 2.0 dropdowns, mode selection, and saved-dimension restoration, plus classic-mode labels and compact layout. Automated regressions cover resolution arithmetic, workflow compatibility, bilingual UI, TXT libraries, module chains, and installation archive validation. No image generation was run, and user workflows/settings were not modified.

### Install or update

Download **ComfyUI-Z-Image-Prompt-Builder-v0.5.1.zip** and extract it into `ComfyUI/custom_nodes`. The archive root is already named `ComfyUI-Z-Image-Prompt-Builder`. Back up workflows and custom libraries before updating; do not keep multiple enabled copies.

For Git installations, run `git pull --ff-only` in the node directory. Restart ComfyUI and refresh the browser with **Ctrl+F5**. Verify the download with **SHA256SUMS.txt**.
