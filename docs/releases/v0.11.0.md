# v0.11.0

## 中文

本次聚焦 **实际执行结果复用、卡片管理与 TXT 抽取结果导出**，保留 11 个节点，不增加端口、依赖或在线服务。

- **结果保存为卡片**：完整节点及对应独立模块可从已确认的历史执行记录保存人物卡／穿搭卡，保留该次实际解析字段，不重新随机，不自动应用或锁定。TXT 替代、空模块及不完整记录不会被猜测转换。
- **卡片管理增强**：按模块和名称搜索、重命名、应用差异预览、选择性导出卡片包，以及整包校验和冲突预览。导入默认跳过同名，覆盖需确认，原单卡格式仍可用。
- **TXT 结果复制／导出**：两个 TXT 节点的“上次随机结果”支持“复制抽中正文”和“导出抽取记录”。只含该条正文与实际种子等信息，不含前置文本或完整词库；空候选可导出诊断但不能复制。
- **结果保护**：校验提交归属和节点实例，处理缓存、早到／迟到回包；打开的面板使用冻结快照，不读取后来修改的草稿。TXT 结果只在会话内保留，不写入工作流。
- **场景逻辑修正**：避免明确的户外／泳池场景随机出现“棚拍间隙调整姿态”；保留手动动作，不重新随机，不从自由提示词或 TXT 猜测场景。

### 使用与兼容

卡片和卡片包不是执行结果 JSON 或工作流，格式不能混用。卡片每节点最多 100 张，文件不超过 1 MB；名称最多 80 个 UTF-16 单位。保存工作流才能保留卡片、锁定、词库和草稿。记录固定字段不保证生成同一张脸。

下载 **ComfyUI-Z-Image-Prompt-Builder-v0.11.0.zip** 并用 **SHA256SUMS.txt** 校验，解压到 `ComfyUI/custom_nodes`；内部目录固定为 `ComfyUI-Z-Image-Prompt-Builder`。Git 安装先备份修改，再 `git pull --ff-only`。重启 ComfyUI，并完整刷新或重新打开浏览器页面；若仍见旧弹窗，先确认前端已重新加载。不要同时启用多个安装副本。

公开范围干净副本通过 208 项 Python 测试、26 组前端回归、15 份 JS 语法和三份生成目录一致性检查；另通过 39 次宿主 CPU 纯文本执行。中英文与 Classic／Nodes 2.0 代表流程、卡片人工审核及保存重开检查已完成。TXT 持久化边界通过新页面重开验证，原标签页同页刷新未证实生效；没有运行生图，不宣称图像质量验证。

## English

This release focuses on **execution-result reuse, card management and TXT selection exports**. The package retains 11 nodes with no additional ports, dependencies or online services.

- **Save results as cards:** capture Person / Outfit Cards from confirmed execution records on the full builder and corresponding standalone modules. Save actual resolved fields without rerolling, applying or locking them automatically. TXT replacements, empty modules and incomplete records are not guessed into structured cards.
- **Manage cards:** search by module/name, rename, preview application differences, selectively export packs, and validate imports with conflict previews. Imports skip existing names by default; replacement requires confirmation. Single-card files remain supported.
- **Copy/export TXT selections:** both TXT nodes offer **Copy Selected Text** and **Export Selection Record** under **Last Random Result**. Only the selected entry and execution metadata are exported, not preceding prompts or the full library. Empty scopes allow diagnostic export but disable copying.
- **Protect results:** submission/node ownership checks handle cached and out-of-order events. Open panels use frozen snapshots, not later draft edits. TXT records remain session-only and are not saved in workflows.
- **Improve scene consistency:** omit a randomly selected studio-adjustment moment in known incompatible outdoor/pool scenes. Explicit actions remain intact; no rerolling or scene inference from free text/TXT.

### Usage and compatibility

Cards, card packs, result JSON and workflows are different formats. Limits remain 100 cards per node, 1 MB per import, and 80 UTF-16 code units per name. Save the workflow to preserve cards, locks, libraries and drafts. Fixed fields do not guarantee face identity.

Download **ComfyUI-Z-Image-Prompt-Builder-v0.11.0.zip**, verify **SHA256SUMS.txt**, and extract into `ComfyUI/custom_nodes`. The internal root is `ComfyUI-Z-Image-Prompt-Builder`. Git users should back up edits before `git pull --ff-only`. Restart ComfyUI and fully refresh or reopen the page; an old dialog can indicate that the frontend has not reloaded. Avoid duplicate active installations.

Public-scope clean-copy coverage: 208 Python tests, 26 frontend suites, 15 JS syntax checks and three generated catalogs; additionally, 39 host CPU-only text executions passed. Representative bilingual Classic/Nodes 2.0 interactions, manual card acceptance and save/reopen checks were completed. TXT persistence was verified by opening a fresh page; the original tab's same-tab reload was not confirmed. No image generation or image-quality validation was performed.
