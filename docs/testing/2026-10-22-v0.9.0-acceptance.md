# v0.9.0 Acceptance / 验收记录

## Scope

This release adds search aliases and feedback, selectable execution-history snapshots with copy/export, and opt-in framing adaptation. It does not add nodes, online services, dependencies, portrait cards, or series-generation plans. The package retains 11 nodes.

## Boundaries and compatibility

- Export is available in the full builder and eight standard modules, **not** the two TXT nodes' Last Random Result dialogs. Run first, then open the node's last-result button and choose **Export This Result**.
- Result JSON is a content snapshot, not an executable workflow or an importable user preset. It does not contain upstream workflows.
- Framing adaptation is off by default and never clears selections. It only omits defined independent fields; compound actions, dresses/bodysuits, fit details, free text and TXT bodies are not semantically split.
- Independent Clothing/Pose adaptation requires explicit upstream camera context from this package. Plain strings may lose that context; a later Camera node does not rewrite earlier text.
- Search aliases do not affect canonical values or random pools. Changed TXT library content changes its identity; unmatched favorites are retained, not silently reassigned.
- No image-quality claims, measured rendering-latency guarantees, or exhaustive host-version compatibility claims are made.
