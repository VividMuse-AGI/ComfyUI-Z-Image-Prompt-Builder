# v0.13.0 发布验收

日期：2026-11-03。开发基线为 v0.12.0。本记录仅说明已验证范围，不保证所有 ComfyUI 版本或第三方扩展组合。

## 实机与人工检查

独立 ComfyUI 0.43.2、Python 3.11.9、CPU 模式，只加载本节点；不覆盖正式安装、不运行生图。

- 中文 Classic：两类卡片保存与收藏；人物卡收藏、重命名、删除的真实 Ctrl+Z／Ctrl+Shift+Z；拍摄方案收藏的真实撤销／重做。
- 人物卡 v1 包实际下载并回导，同名跳过不改变收藏；保存工作流并刷新后卡片及收藏保留。
- 英文 Nodes 2.0：两类面板可操作，无匹配时禁用应用；取消收藏显示隐藏原因；导出筛选保留隐藏勾选，完整名单与计数一致。
- 人物、服装独立节点只显示所属模块；场景方案卡禁止保存不属于该节点的摄影和视觉表现模块。
- 用户确认实体中文输入法确认候选字、Esc 关闭及人工收尾没有问题。测试后恢复原界面设置。
- 捕获的浏览器 error 为空；宿主存在 defaultValue 弃用警告，不影响上述验证。

拍摄方案重命名／删除等边界由自动化覆盖，不声称逐项完成实机矩阵。未验证图像质量或人脸一致性。

## 干净副本检查

从明确纳入的 170 个文件构建独立干净副本，Python 3.10.11 的 216 项测试、Node 22.20.0 的 30 个前端脚本、19 个 JS 语法检查全部通过。三份生成目录一致，11 个节点可加载，安装包合同包含两个新增组织模块。相对文档链接有效；凭据特征扫描无匹配（不等于全面安全审计），测试前后源文件哈希一致。

仅本地使用的外部数据集测试和历史验收记录不属于发布范围，未纳入上述计数。完整应用代码与实机验收相同；发布准备额外补充安装包依赖检查和版本文档。

## English

Date: 2026-11-03. Baseline: v0.12.0. This record describes the verified scope, not every ComfyUI version or extension combination.

Live checks used isolated ComfyUI 0.43.2 with Python 3.11.9 in CPU mode, loading only this package. No production installation changes or image generation were involved.

- Chinese Classic: saving/favoriting both card types; real host undo/redo for content-card favorites, renaming and deletion, and shoot-plan favorites.
- Actual content-card pack download/reimport; skipping an existing name preserves its favorite. Saving and refreshing retains cards and favorites.
- English Nodes 2.0: both panels work; no-match states disable application; unfavoriting explains why the card is hidden; export filtering preserves hidden selections with matching counts and a complete export list.
- Standalone Person and Clothing panels restrict their module scope. Scene cards cannot capture Camera or Visual settings from the Scene-only node.
- The user confirmed native Chinese IME candidate acceptance, Escape handling and final manual checks. Original UI settings were restored.
- No captured browser errors; the host emitted defaultValue deprecation warnings without blocking these checks.

Shoot-plan rename/delete edge cases rely on automated coverage rather than an exhaustive live matrix. Image quality and face consistency were not evaluated.

A clean copy containing the 170 release files passed 216 Python 3.10.11 tests, 30 Node 22.20.0 frontend scripts and 19 JS syntax checks. Three generated catalogs were unchanged; all 11 nodes loaded; the archive contract includes both new organization modules. Relative documentation links resolved, credential-pattern scanning found no matches (not a comprehensive security audit), and source hashes were unchanged by testing.

Local-only external-dataset tests and historical acceptance notes are excluded from the release and these counts. Application code matches the live-tested copy; release preparation additionally updates the package dependency check and version documentation.
