# v0.17.0 发布前验收

日期：2026-11-06。状态：功能、有限实机验收及最终公开范围检查通过。本记录证明发布前验收，不代表远程发布成功；实际状态以 GitHub Release 为准。生产安装不在此次发布范围内。

## 范围与已有证据

- 本版增加只读随机采样解释、前端严格校验、当前状态与历史结果分离，以及 TXT 零／单／多候选说明。
- 阶段二干净副本通过 236 项 Python、36 组前端及 25 项语法检查；三份生成目录保持一致。297 组固定输出／链式上下文／原有 UI 元数据和 11 个节点契约与 v0.16.0 基线一致。
- 隔离 ComfyUI 0.44.0／前端 1.57.6、离线 CPU 环境完成 13 次文本执行，中英文及 Classic／Nodes 2.0 代表入口通过。补验实际场景联动后的摄影、光线二次采样和覆盖说明。
- 实测种子 42、43 在独立视觉模块各只有一种候选组合，正文相同，面板解释一致。历史切换使用实际提交种子，不以当前控件重算。
- 锁定→解锁后仍保留具体值，只有使用原随机按钮才启用随机。TXT 3／1／0 候选范围说明符合实际，空范围不误抽其他模块。
- 保存后新页面重开保留字段、自由文本、种子及锁定，临时历史清空，再执行正常；未刷新或丢弃其他未保存工作流。
- 用户委托代理完成最后可读性检查：1280×720 下说明与外层面板可滚动、无横向溢出，按钮无遮挡，Esc 关闭及重新打开正常。说明为 13px，较密集但非阻断问题。

本版没有改变随机算法或候选库，不保证所有随机组合的语义一致性。没有生图，也不声明所有宿主版本或第三方扩展兼容。
