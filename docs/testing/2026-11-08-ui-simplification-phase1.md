结论：实现与定向自动化回归通过，实机视觉验收待补。未提交、推送、发布或同步正式安装。

## 已完成的调整

- 完整节点和八个独立模块显示“查看结果 / View Results”；保留内部 widget 名称、非序列化属性及输出端口。
- 结果正文前置，常用操作为复制中文、复制英文和“更多”；更多中保留结果 JSON 导出与两种手动复制。
- 保存卡片、随机与组合说明、字段与技术详情默认折叠。当前配置与所选执行说明分区，实际种子和历史设置差异警告仍在正文前。
- 卡片保存仍使用所选执行的解析数据，保留节点归属、可用性及旧记录限制。画面基础独立节点不显示不支持的卡片区域。
- 两类 TXT 节点显示“查看抽取结果 / View Draw Result”；复制与导出置于正文前，候选数量及解释折叠。零候选在顶部明确提示；抽中正文仍不含前置拼接文本。
- 复制成功提示改为“已发送复制请求”并短暂显示，未读取系统剪贴板。结构化结果复制失败时保留手动选中文本兜底；TXT 沿用选择正文手动复制。
- TXT 复制提示增加请求编号保护，前一次计时器不会清除后一次相同文案。界面文案变更未调整抽取或渲染算法。

## 保持不变与尚未验收

本阶段只调整前端展示、复制状态提示、翻译映射及测试。此前未发布的 v0.20.0 两条手部动作与其他工作区变更保留，不归为本阶段新改动。未修改后端字段、提示词生成、随机池、卡片／结果 schema 或版本号。

以下项目仍需在隔离 ComfyUI 环境补验：

- 经典和 Nodes 2.0 的中英文代表布局，包括约 900 CSS 像素高视口及较窄视口下的正文、长按钮、展开菜单和滚动。
- 真实鼠标／键盘展开、Esc、焦点和输入法交互；自动化事件断言不能代替宿主行为。
- 干净浏览器会话中的系统复制与实际下载。不能把本次模拟 `writeText` 取值通过称为系统粘贴验收，也不对正常验收标签页调用会虚拟化剪贴板的工具接口。

第二阶段管理入口、第三阶段随机／清空文案和 README 重排未开始。本轮没有生图，没有修改运行中的 ComfyUI 安装。
