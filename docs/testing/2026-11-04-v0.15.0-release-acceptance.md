## 实机与人工检查

独立 ComfyUI 0.44.0 / 前端 1.57.6，Python 3.11.9，CPU 离线环境；只执行三次纯文本工作流，未生图或更改生产安装。

- 中文 Classic：人物＋发型＋动作组合修改 39 个字段、新增 19 项锁；核对全部 114 个控件。一次撤销恢复原字段与 1 项锁，一次重做恢复组合与 20 项锁。
- 当前设置及实际执行结果均可保存发型、动作卡。保存文件中的结果卡与后端实际候选逐字段一致。
- 保存刷新后 8 张卡、2 个收藏、20 项锁和字段保持；组合临时选择回到保持当前。
- TXT 替代阻止包含动作的整次组合；取消该模块后仅更新 9 个发型字段，TXT 原文不变。
- 英文 Nodes 2.0：两个新类型独立节点保存、应用、锁定和结果保存通过，仅显示自身类型。
- 新卡与原穿搭、拍摄方案混合应用修改另外 49 个字段，其他字段、卡库和锁保持；一次真实撤销／重做通过。
- 普通 1280×720 视口的长弹窗和英文内置文案通过；用户明确确认原生文件选择导入两个独立节点，以及缩小窗口后预览／应用／关闭的滚动操作正常。未记录人工使用的具体缩放倍数。
- 测试后恢复独立环境中文 Classic 设置。已连接输入、异常回滚、过期预览等更多边界由自动化覆盖，不宣称所有宿主版本或第三方扩展组合均已验证。

用户曾从素材收藏入口导入卡片包，正确被格式校验拒绝；已明确两种导入入口并补充双语说明。未将入口误用视为卡片损坏，也未修改产品错误提示。

English Nodes 2.0 covered both standalone nodes, their own card actions and result saves. Combining new cards with existing Outfit and Shoot Plan Cards changed a further 49 fields; unrelated values, libraries and locks stayed unchanged, including after real undo/redo. The 1280×720 layout passed. The user confirmed native file-picker imports into both standalone nodes and smaller-window scrolling; exact manual zoom factors were not recorded. Chinese Classic settings were restored. Further fault, link and stale-preview cases rely on automated tests, not an exhaustive host/extension matrix.

New public files are limited to the transaction module, these release notes and this record, alongside edits to tracked implementation, tests and guides. Local plans, stage logs, screenshots, fixtures and personal paths are excluded from newly published files. Archive validation now requires the transaction dependency. A tagged release ZIP will only be generated after the separately authorized commit/tag/release steps.

Source and candidate hashes remained unchanged by testing.
