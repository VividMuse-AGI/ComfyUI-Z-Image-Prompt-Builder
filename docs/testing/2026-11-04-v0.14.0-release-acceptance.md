# v0.14.0 发布验收

日期：2026-11-04。开发基线为 v0.13.0。代表性实机验收于 11 月 3 日完成，用户于 11 月 4 日确认操作体验无问题。本记录限定于已验证范围，不代表所有 ComfyUI 版本或第三方扩展组合。

## 实机与人工检查

独立 ComfyUI 0.43.2、前端 1.57.4，CPU 模式，只加载本节点；不更改正式安装或提交生图任务。

- 中文 Classic：组合人物、服装、场景和摄影共 57 个字段，新增 41 项锁，已有发色锁保留。一次真实 Ctrl+Z 全部恢复，一次 Ctrl+Shift+Z 恢复应用结果。
- 保存刷新后字段和锁保留，面板临时选择不持久化，重新打开默认保持当前。
- 英文 Nodes 2.0：仅应用视觉表现的 12 个字段，真实撤销／重做正常。预览、模块范围和锁定控件使用英文；无变化组合禁用确认。
- 人物 TXT 替代阻止人物与服装整次组合；改为保持人物当前内容后，服装可单独预览。取消操作不写入字段或锁。
- 对保存文件逐项核对 114 个命名控件、锁和两类卡片库；未选内容、自由提示词、种子、比例和分辨率保持不变。
- 原生下拉展开及选项点击、滚动、Escape 取消可用。测试后恢复中文 Classic；本轮捕获的浏览器 error 为空。用户确认体验无问题。

过期来源、非法卡片、连接输入和刷新失败恢复等边界由自动化覆盖，不声称全部进行了实机矩阵测试。新面板没有文本编辑框，输入法合成保护使用模拟事件覆盖；未评估图像质量或人物一致性。

## 干净副本检查

177 个明确发布文件的独立干净副本通过 Python 3.10.11 的 217 项测试、Node.js 22.20.0 的 32 个前端脚本及 21 个 JavaScript 语法检查。三份生成目录内容一致，11 个节点可加载，安装包合同及相对文档链接检查通过。凭据特征扫描无匹配（不等于全面安全审计），测试前后源文件哈希一致。

本次新增公开内容仅为组合核心、面板、两份前端测试、使用说明、发布说明及本验收记录。历史本地设计、截图、个人路径和外部数据集测试不加入本次新增发布文件。功能代码与实机验收副本一致；版本文档另行更新。

## English

Date: 2026-11-04. Baseline: v0.13.0. Representative live checks completed on November 3, with user interaction approval on November 4. Coverage does not imply compatibility with every ComfyUI version or extension combination.

Live checks used isolated ComfyUI 0.43.2 with frontend 1.57.4 in CPU mode, loading only this package. No production installation changes or image generation were involved.

- Chinese Classic: one combination changed 57 Person, Clothing, Scene and Camera fields and added 41 locks while retaining an existing hair-color lock. One real host undo restored everything; one redo restored the applied state.
- Saving and refreshing retained values, locks and card libraries. Reopening reset temporary selections to Keep Current.
- English Nodes 2.0: applying only the 12 Visual fields, real undo/redo, English previews and module/lock controls passed. No-op combinations disable confirmation.
- A Person TXT replacement blocked a combined Person/Outfit application. Keeping Person unchanged allowed an Outfit-only preview; canceling did not write values or locks.
- Saved files were checked across all 114 named controls, locks and both card libraries. Unselected content, free text, seed, ratio and resolution stayed unchanged.
- Native dropdown expansion/selection, scrolling and Escape cancellation worked. Chinese Classic was restored, captured browser errors were empty, and the user approved the interaction.

Stale sources, invalid cards, connected inputs and refresh rollback rely on automated coverage rather than an exhaustive live matrix. The new panel has no text editor; composition guards use simulated events. Image quality and identity consistency were not evaluated.

A clean copy of the 177 explicitly selected release files passed 217 Python 3.10.11 tests, 32 Node.js 22.20.0 frontend scripts and 21 JavaScript syntax checks. Three generated catalogs were unchanged, all 11 nodes loaded, and archive-contract and relative-document-link checks passed. Credential-pattern scanning found no matches (not a comprehensive security audit); source hashes were unchanged by testing.

New public files are limited to the combination core, panel, two frontend tests, guide, release notes and this record. Historical local plans, screenshots, personal paths and external-dataset tests are excluded from newly added release files. Application code matches the live-tested copy; version documentation is updated separately.
