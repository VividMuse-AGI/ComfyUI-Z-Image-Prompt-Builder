# v0.16.0 发布前验收

日期：2026-11-05。状态：功能自动化、有限实机验收及最终提交范围打包检查通过。本记录证明发布前验收，不代表远程发布成功；实际状态以 GitHub Release 为准。本机生产安装不在此次发布范围内。

## 范围

本版新增导入指引、只读卡片摘要及显示适配器，并接入现有卡片、拍摄方案、快捷组合、素材收藏和用户预设入口。保持原格式校验、同名确认、整包原子处理、异步生命周期和事务保护。

提交范围为现有已跟踪文件的相关修改，加上三个运行时模块、三个前端测试、v0.16.0 双语发布说明及本记录。历史未跟踪方案、私人路径、截图、测试工作流和本地日志不加入新增公开文件。

## 已完成的功能验收

- 同一功能候选的干净副本通过 222 项 Python、35 个前端测试脚本、25 个 JavaScript 语法检查；三份生成目录重建不变。
- 本版界面测试包含 41 个用例组，使用真实模块与 schema、模拟 DOM；既有 297 组固定输出摘要不变。
- 独立 ComfyUI 0.44.0／前端 1.57.6、Python 3.11.9、PyTorch 2.9.1+cu130，离线 CPU 模式。中文 Classic 与英文 Nodes 2.0 实机抽验通过。
- 真实文件选择器误选卡片包到收藏入口时，正确提示入口且收藏不变；正确入口确认新增两张卡，不自动应用。
- 内容卡、拍摄方案、独立发型摘要正确；800×600 窄视口换行及滚动正常，关闭等操作可达。
- 快捷组合只改动发型、姿态动作和摄影的 26 个字段，增加 9 个发型锁；一次真实撤销／重做后，保存文件的全部控件值及属性分别与应用前／后完全一致。自由提示词、种子、画面基础及其他模块不变。
- 实机环境 186 个候选源文件测试后哈希不变，环境设置恢复中文 Classic。未执行生图或改动生产环境。

这些是有限代表性抽验，不是所有宿主版本／第三方扩展的完整兼容矩阵，也不保证生成图片一致。

## 最终公开范围检查

188 个明确文件的干净副本通过 222 项 Python 测试、35 个前端脚本及 25 个 JavaScript 语法检查，三份生成目录重建不变，测试前后源文件哈希一致。11 个节点正常注册；45 个运行时 Python／JavaScript／JSON 文件与已实机验收的候选一致。

固定根目录内存归档通过版本号、必备依赖、重复／越界路径及 CRC 校验。检查的 61 处文档相对文件链接均有目标文件，未据此宣称外网或全部锚点可达。高置信 API 凭据模式未匹配；这不是全历史或全面安全审计。

## 发布准备边界

准备阶段使用 0.16.0 待发布文案与 v0.15.0 安装入口。用户授权正式发布后，统一更新为 v0.16.0 下载入口及 2026-11-05 发布日期；此轮只定稿文档，运行时代码与实机验收候选保持一致。

安装包校验要求包含三个新增运行时依赖。准备阶段仅检查固定根目录候选归档合同；正式安装包必须从经过测试的实际提交／标签生成，不将未提交候选 ZIP 冒充正式附件。
