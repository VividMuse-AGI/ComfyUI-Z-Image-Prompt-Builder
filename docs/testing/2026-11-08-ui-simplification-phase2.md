## 入口和布局

九类结构化节点的右键菜单整理为两个入口，不增加节点常驻控件：

| 入口 | 内容 |
| --- | --- |
| 我的预设与卡片 / My Presets & Cards | 整套预设、模块卡片、组合应用 |
| 随机设置与检查 / Random Settings & Checks | 模块锁定摘要、模块锁定／解锁、可展开的字段级锁定、组合检查 |

完整节点提供三个管理页签。画面基础独立节点只提供整套预设；其他独立模块按实际支持范围提供整套预设和模块卡片，不显示组合应用。

模块卡片页内按类型选择人物、发型、穿搭、姿态动作或拍摄方案。拍摄方案仍只包含场景、摄影和视觉表现，没有新增卡片格式。页签、卡片类型及组合页返回操作在同一个原生对话框中切换内容，不叠加管理弹窗。

导入、导出、重命名、删除与卡片包操作放入“管理…”折叠区。应用差异、组合确认、导入预览和原有覆盖确认保留。卡片应用仍是显式动作，导入不自动应用。

模块锁定摘要区分未锁定、部分锁定和全部锁定，并展示字段数。字段级选择只在点击“保存锁定”后生效；解锁不改变当前字段值，TXT 替代和连接输入的原有限制保留。组合检查仍只检查已知规则，不代表生图验证。

## 兼容和会话保护

统一管理面板将现有卡片、拍摄方案、组合及预设界面作为可销毁的内容区挂载，复用原有业务函数与校验。旧独立面板构造函数保留作为兼容调用路径及回归夹具；正常右键入口和公共返回卡片入口进入统一管理面板。

本阶段没有变更节点标识、输入端口、widget 序列化位置、提示词生成、随机候选、存储键、JSON schema 或卡片容量。没有对用户保存的卡片执行迁移。已有卡片和组合事务的撤销边界保持不变，未扩展预设或锁定操作的撤销承诺。

切换页签或卡片类型时销毁原内容区，使其待完成文件读取和未确认预览失效。关闭、重配置、移除节点或切换工作流后，旧控件不能写回新会话。

额外补查原生关闭事件延迟：原生对话框的 `open` 已为 false、内容区的清理回调尚未触发时，内容区也必须检查外层对话框会话。已加入此保护，预设、普通卡片、拍摄方案的三个延迟读取用例均通过。

## 定向自动化结果

Windows；Node.js 22.20.0、Python 3.10.11，沿用便携运行时。以下 15 个前端测试脚本通过；部分脚本使用真实 Python 节点输入定义或后端夹具，但本轮没有另外重复跑全套 Python 测试。

| 测试脚本 | 主要覆盖 |

| `frontend_workflow_tools.mjs` | 预设恢复与校验、字段锁定、组合检查 |
| `frontend_card_management.mjs` | 卡片搜索、重命名、导入导出、差异及会话保护 |
| `frontend_content_cards.mjs` | 真实输入定义、模块卡片、锁定与原子校验 |

新增 32 组统一管理用例分为：

- 18 组：九类节点 × 两种语言，页签支持范围正确，切换不写字段、不增加控件、不嵌套原生对话框。
- 3 组：预设／普通卡片／拍摄方案导入过程中切换页签或类型，迟到读取不得写入。
- 3 组：外层窗口已关闭、关闭事件尚未处理时，迟到读取不得写入。
- 2 组：双语类型切换、组合页返回、离开后旧确认失效、返回后清空临时选择。
- 2 组：双语部分锁定摘要、字段草稿、显式保存、模块解锁、TXT 与输入连线保护。
- 2 组：完整节点／人物独立节点在统一面板中保存、应用、重命名和删除卡片；取消删除不写数据。
- 2 组：页签键盘操作、输入法状态、节点重配置／移除后的失效保护。

本轮三个修改的前端源文件通过 `node --check`，`git diff --check` 通过。最后增加的两组保存／应用用例及字段标签回退后，已重跑对应可用性脚本；没有批量改变旧输出断言来接受行为漂移。
