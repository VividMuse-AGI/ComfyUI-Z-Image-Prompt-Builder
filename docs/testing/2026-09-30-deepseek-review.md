## Behavior details / 修复边界

- 中文已有的精简规则仍有效：姿态动作和场景保留核心字段，摄影距离主要在详细档输出；视觉配色和成像细节有数量裁剪。英文遵循相应规则，保留中文实际保留的字段。单独字段的原子回退继续有效。
- 妆容依赖、非进阶染发的隐藏字段及明确穿搭结构的隐藏分支继续由解析阶段控制；精简／标准的近景鞋袜省略继续生效。
- 不把未选择的图案强制补进精简的已命名衣物；空白结构下的独立属性仍可以输出。
- 十套固定预设的选择值与基线逐项相同。中文精简／标准输出与基线一致；九套详细输出仅去掉衣物名前的重复材质，仍保留完整材质描述。英文输出有本次明确的保留字段、语法及译词变化。
- 已逐套比较输出后更新固定预设快照。新增语义回归防止将错误输出简单固化为新快照；原英文“精简省略材质”测试改为与中文保持一致。
- 随机场景的候选优先级发生修正，因此同种子随机场景允许与已发布版本不同；同一版本、同一输入、同一种子的确定性仍有回归覆盖。

- 未收录池与明确空池、未使用的全局池、未知／旧预设名、显式服装结构规则。
- 全部 9 条参考场景通过受控候选注入进入真实替换路径，确认重新布光采用新大类，而不是旧场景 id。这个测试验证路径，不替代真实照片或模型生图验收。

## Reproduction / 复测

在待发布源文件集根目录运行，与现有 CI 一致：

```sh
python -m unittest discover -s tests -p "test_*.py" -v
python scripts/generate_frontend_i18n.py
python scripts/generate_resolution_catalog.py
```

生成目录应与待测文件逐字节相同。用 Node.js 对 `web/js/*.js` 执行 `--check`，并逐个运行 `tests/frontend_*.mjs`；前端测试需要 `PYTHON` 指向可用 Python。可选运行 `scripts/validate_txt_execution.py --comfy-root <ComfyUI checkout>`，验证隔离的 CPU 纯文本执行，不提交服务器队列任务。
